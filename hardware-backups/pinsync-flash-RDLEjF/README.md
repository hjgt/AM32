## 结论与下一项判别（尚未修改/实施）

本窗口没有得到支持PA3/PA7为三相中性点的证据，不据此切换比较器参考。
PA3与C关联是真实记录现象，但PA3正好为ADC1 rank4，前一rank为C；
6.5cycles下的输入高阻/采样电荷残留或板级耦合也可能造成类似现象，不能认定铜线连接。
PA7近0也不证明引脚物理悬空/接地，仍受输入建立时间、极性和观察窗口限制。

优先对照：只延长PA3采样保持时间，保持原三相rank次序/采样时间，
按新的转换长度修改诊断有效窗口检查；不提高PWM或功率，不改变中性点。
这会增加ADC1 JEOS延迟，仍需作为短时诊断而非最终控制版本。
若关联显著随采样时间改变，更支持采样建立问题；不变也不单独证明物理接线。
