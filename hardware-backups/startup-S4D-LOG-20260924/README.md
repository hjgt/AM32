## 解释边界与后续

用户本轮未观察到反转，但仍失败，说明肉眼可见反转不是失败的
必要前兆；不证明完全没有短时反向运动。当前证据更支持调查
启动驱动与转子运动的衔接/初始状态依赖，而不是继续放宽检测。
软件已预备却没有穿越、换相后没有预侧都真实出现在记录中；
不能据粗采样区分真正 BEMF、残留电流/换相暂态，首边沿是否属于
可靠机械运动也尚不能定论。1.2 ms 波形不足以解析首个 0.61 ms
边沿的全部过程，必要时应在此处作高密度触发对照。

本轮只采集与归档，未改控制策略或刷写。板上仍 S4D-LOG 台架版，
没有堵转保护实机可用或飞行可靠性的结论。
