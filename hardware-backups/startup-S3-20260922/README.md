## 详细记录

保留首次完成失败第 1 次和首次完整观察成功第 3 次，分别 14/9 扇区，
无溢出，段落连续，全部 issues=0。没有保留第 2/4/7/11 次的逐段
闭环波形，不能据摘要判定它们是机械失步、检测漏报还是接管计时问题。

第 1 次：0 个接受边沿，13 次约 22.5 ms 无反馈试探；初始 step 1
整个扇区处于预期前侧，没有产生过零。后续多次电压反向跨越或一直
在同侧。仍不能从电压跨越方向推断机械转向，亦不能据此证实功率不足。

第 3 次：先有 3 次无反馈试探，随后六个合格边沿约出现在
85.100、98.923、108.253、116.158、122.943、128.501 ms。
前五个边沿到实际换相记录约 18–20 µs，确实不再等待固定节拍。
最后一个边沿后约 2.597 ms 完成接管（131.098 ms），之后 1002 个
闭环边沿并持续满 1 秒，没有闭环超时。第二至第六边沿间隔逐渐缩短，
说明本样本的启动反馈节奏不是固定周期。

记录器内部最大边界 400 cycles = 2.500 µs，最大采样 601 cycles =
3.756 µs；不等同于完整 ISR 时间。当前堵转保护 Off，原生 trip_count=0，
此次停机原因均为台架截止或闭环丢反馈，不能视为原生保护验收。
