## 结论与边界

本次失败在连续反馈接管之前。不能归因于闭环进角过大，也不支持简单说ADC完全没看到变化。
首相反向穿越不能单独证明机械反转、相序接错或比较极性错误：这里是受驱动状态下的三相顺序采样及重构参考，并非独立转向传感器。
尚不足以确定首次换向应提前还是推迟，也不应据此取消前侧资格要求。
下一步只需补一条相同设置下成功启动后立即停稳读取的完整前缀，对照首相运动和换相边界；避免继续启动覆盖它。
