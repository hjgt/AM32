边界超过预先设置的 5 µs 检查线。反汇编证实 `fdTraceEvent` 在该路径

这是需要修正的诊断开销；尚未证明它导致了起转失败，也不能宣称这轮

控制规则，复测实际耗时；不同时改变功率、定位、接管门槛或 ADC 判定。
