## 结论与局限

差异在第一次无反馈超时之前已经存在；本失败从未执行seed-delay、
后续边沿延迟或闭环交接，因此不应继续把它解释为首次边沿后的延迟错误。
没有任何接受边沿，也不能用“孤立边沿误判”解释本次失败的起因。
优先调查初始位置/施力与第一次超时换相的关系。负侧裕量一直未到零，
可能涉及运动不足或未按预期运动，也未排除模拟采样/驱动问题；仅靠
这些ADC样本不能判定真实转子角度、方向或“再等多久必然能起转”。
不放宽pre_seen，不加功率、不延长300ms截止；未授权即不改控制代码。
