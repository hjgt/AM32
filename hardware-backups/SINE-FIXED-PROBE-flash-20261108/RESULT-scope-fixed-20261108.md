# 固定相角功率端照片：约1us差异已出现，下一项载波对照（2026-11-08）

用户提供IMG_3469.HEIC，黄A、蓝B，认为外观仍与不工作的波形类似。本版仍为SINE-FIXED-PROBE：固定150/269/29、power6、24kHz、死区2.3us、最多100ms。此前MCU引脚记录244可用样本全部吻合，包括16个AH/BH不同窗口及2个AH+BL同时高窗口。

## 本张可读信息

屏幕实际设置5us/div、两路5V/div。蓝B主下降沿比黄A早约1.0～1.2us（照片估算，受透视/线宽影响），在左右两个周期边沿上方向相符；与门控时序540ticks/160MHz−368ticks/160MHz=3.375−2.3=1.075us接近。

因此功率端已有短暂相间差异，不能继续说“桥把所有PWM差异完全抹掉”。约8V的对地公共方波占大部分，A-B有效差异只集中在边沿附近。两通道竖直偏移由各自零点决定，不当作相间直流差。

上升区域包含尖峰和中间平台，蓝线早期尖峰后并非一直保持完整高电平；不能把视觉上最早的上冲当作持续2.3us的满幅−Vbus脉冲。仅凭这张照片不能精确积分A-B净伏秒，不能宣布净电压为零或反向。无需再用同一照片证明一个未量出的积分值。

## 当前优先假设

正弦power6的三相命令最大差仅3.375..3.9125us，与本板2.3us死区同量级。当前证据支持“正弦低调制幅值与本板死区/续流行为不匹配，导致有效激励很弱”的工作假设，优先级高于MCU未实际输出PWM；仍未证明这是全部不起转根因。

原先共同平移只改变共模、不提高三相比较值差，不能修复所有死区电压失真。死区期间相线由电流方向及续流状态决定；电流接近零时会有不连续导通、中间电平及振荡，这时不能直接套用连续电流的固定±死区电压误差，见[Microchip官方分析](https://microchiptech.github.io/mcaf-doc/6.0.2/algorithms/dead-time-comp.html)。[TI官方说明](https://software-dl.ti.com/mcu-sdk/esd/AM13E2X-SDK/26_01_00_03/exports/docs/docs/am13e230x/user_guide/chapters/solutions/am13e230x/motor_control/control_advance_features.html#dead-time-compensation)同样指出死区的输出电压失真在低调制、低速条件下明显。

## 建议下一项：只改载波24→12kHz

仍固定150/269/29、power6、100ms、原死区2.3us、传感器更新与被动GPIO记录；不直接转为3秒旋转模式。降低载波而保持PWM比例，使理想相间平均电压基本相同，死区占周期比例从约5.52%降到2.76%。

按当前实际表与整数公式预测：

| 项目 | 现板24kHz | 候选12kHz |
| --- | --- | --- |
| ARR | 6665 | 13330 |
| CCR A/B/C | 3603/3063/3597 | 7205/6125/7193 |
| A/B理想占空比差 | 8.1008% | 8.1014% |
| A/B命令边沿间隔 | 3.375us | 6.750us |
| AH+BL门控交叠 | 1.075us | 4.450us |

最后一行仅指MCU门控交叠，不等于全部绕组伏秒。载波变化也影响电流纹波和开关过程，若输出差异/电流/吸力明显增强，将支持死区相关的有效激励不足，但不单据一次结果宣称唯一根因。100ms遥测显示可能漏掉峰值，候选应另保存试验期间传感器更新次数、基线/峰值电流与最低母线值。

实现前需要同时核对RAM频率覆盖、fdBenchConfigOk中目前写死的24kHz条件、ARR/三路CCR、GPIO解析器周期范围、原100ms截止；保留24kHz关闭开关构建一致性验证。不能只改频率数字而漏掉配置门禁。

**该12kHz方案尚未实现、编译或烧录。** 本轮仅分析图片和离线计算，未访问/改变目标，板上仍SINE-FIXED-PROBE24kHz，读取ELF保持现版。先前power6→10是可用的幅值对照，但会同时提高理想电压；载波对照更直接地改变死区相对影响，故优先。
