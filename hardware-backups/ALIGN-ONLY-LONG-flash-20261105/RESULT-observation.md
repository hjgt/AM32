# 第二矢量300ms：肉眼收敛观察，2026-11-05

程序：ALIGN-ONLY-LONG，第一定位30ms、第二定位总300ms，名义330ms关断，不发车、不重试。见 [烧录记录](flash.json) 与 [固件说明](../../test-firmware/fd6288-ALIGN-ONLY-LONG-20261105/README.md)。

## 用户反馈

- 不再出现此前所述的大幅摆动，像被磁铁牢牢吸住一样，稳定在定位位置。
- 有非常微小的振荡，但整体呈牢牢吸住的状态。
- 用户认为从这个状态直接发车应更容易成功，并询问第二段300ms是否过长。
- 本次未报告准确次数、各次初始位置、同步录像或与PB7对应的运动时刻；不补作推断。没有执行启动，尚无本版起转成败数据。

## 判断与下一步建议

较长保持下的肉眼收敛，结合短版在改变初始位置后偶有大幅双向运动，提高了定位过程尚需收敛这一解释的优先级。但尚不能测定原90ms发车时的速度，也不能确定300ms为最短所需时间。

建议下一轮先以第二段300ms稳定保持作为参考，在结束时直接切到基线首发矢量并沿用前侧保护，验证“稳定定位之后是否能接上启动”。保持矢量、占空比与原启动判决不变；明确区分本轮330ms关断的观察版与后续拟议的启动版。

若300ms参考启动能跨不同初始位置顺利接上，再逐步缩短第二段，例如200ms、150ms，并根据现象决定下一档。不要同时缩短定位和改变启动判决，避免无法区分定位未收敛与首发本身的问题。记录初始位置是否改变；不把同一停点的连续重复当作随机初始状态验证。

本条为观察记录和测试建议，未实现或烧录新的启动版。
