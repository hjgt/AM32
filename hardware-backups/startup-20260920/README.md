# 2026-09-20 A 记录版起转采样

## 第一组：用户起转三次，单次记录只保留第一次

用户报告前两次正常、第三次异常，随后确认回零、转子停稳，三次之间
没有断电或重启。全程未由工具发送油门。读取在确认停稳后进行，不 halt、
不 reset、不刷写，也没有为抓数据而要求保持故障。

### A-capture-001-first-of-three.bin / .bin.json

- 固件 A，主 HEX SHA `24ff2551ca5908ce1afc421003b9a8e4d0725958540749ce3239f9449c7a82ee`。
- capture_id=1，与起转前手动准备的记录编号相同；没有重新准备或重启。
  记录器是一次性触发，约 1 秒或回零后冻结，后续起转不自动覆盖。
  因而此记录对应第一次用户报告正常的起转，**不是第三次异常样本**。
- 记录时长 1000224 µs，冻结原因是 1 秒采样上限，不是回零或故障关断。
- 共消费 14357 个 ADC 样本，合格过零计数 734；保留首 64 + 尾 512 个。
  共有 1477 个事件，保留首 32 + 尾 128 个。中段被环形缓冲覆盖，缺口
  已由 JSON 显式标记，不能称为完整连续波形。
- 保留首段约 20.013 ms / 42.517 ms 各有一次超时强制推进。A 把
  约 22500 µs 的超时送入原过零函数，周期估计从 5000 µs 拉到 9376、
  12658 µs。这是控制行为的实测证据，**不是第三次异常根因的证明**。
- 首段随后取得过零；约 97.510 ms 开始执行换相等待时，测得间隔
  7140 µs、IIR 估计 10669.5 µs、等待 3001 µs。末段已连续换相，
  约 1 秒时输入=447（约 20% DShot 范围）、过滤电流 0.65 A、电压 7.52 V。
  不将该电流当成瞬时相电流，也不据此验证整段负载或最高转速表现。
- 记录函数内部最大耗时：sample=229 cycles（1.43125 µs），
  event=281 cycles（1.75625 µs），160 MHz 时基。这不包含全部函数开销、
  ISR 阻塞等待或系统最坏延迟，不能宣称记录器完全无扰动。
- 原始记录 SHA-256：
  `47723d7a242f5546cbdaf8609f746508aadb0f633c5b3db1d02e7f7738135bf3`。

### A-after-three-stopped-ram32k.bin / .bin.json

另外保存三次试验后完整 RAM 及旧 ADC 诊断环形记录，不重置累计数据。

- 自启动以来 reset_start=3、reset_timeout=148、reset_desync=0、
  reset_fault=0、accepted=9940、rejected_early=130、rejected_unarmed=35293。
- stuck_rotor_trip_count=0，drive_safety_limit_trip_count=0。
  堵转保护仍关闭，不能据“没有触发”推断故障时保护有效。
- 旧环形记录最后 32 个合格边沿没有时间戳或起转编号，可能留有前一次
  正常运行的数据；不能全部归入第三次，不能据其看似连续就否定用户的
  第三次异常，也不能用累计 148 次超时证明全发生于第三次。

下一轮须每次由工具重新准备，用户**只起转一次**，无论正常与否都回零、
停稳、保存，再决定是否进行下一次。保持设置不变，异常立即停，不硬顶。

## 第二组：独立异常起转，capture_id=2

重新准备后只起转一次，用户报告 20% 油门、约 2 秒、2.5 A，异常后不能
恢复。确认回零、停稳、仍供电后，只读取得以下资料；未 halt/reset/刷写。

### A-capture-002-abnormal.bin / .bin.json

- A HEX 与第一组相同，RAM 设置逐字节相同；首秒冻结约 1000037 µs。
- 全部 135 条事件完整保留：START 1、COMMUTATE 45、TIMEOUT 44、
  ZC 函数调用 44、STOP 1（仅冻结记录）。所有 ZC 调用均来自强制超时，
