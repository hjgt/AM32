## 结论与下一步边界

已经取得真正接管成功与失败的可比记录，无需为凑次数继续反复起转。
当前主要问题仍在定位/开环带转到有效反馈序列建立之前，不能仅归因于
六边沿接管门槛或日志开销。固定换相节奏与实际反馈相位未可靠匹配是
优先检查方向，但这仍是待验证假设，不是转子位置测量结论。

下一候选应先对照用户曾反馈约 80% 可用的 `2c1b5fa` 控制基线，
审查后来加入的固定定位/开环加速策略，再选择最小控制修改。
不恢复曾损坏的设置，不直接翻转过零极性，不只降低接管门槛，
不把继续加功率当作已证实的解法。不同会话的电压/设置及试验方式不同，
不可把用户旧估计与本次 1/8 当作受控成功率比较。
本轮仅读取和整理证据，板上仍为 S2D2 台架版，不可作为飞行验收版本。
