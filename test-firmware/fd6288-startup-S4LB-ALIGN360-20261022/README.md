## 唯一控制变化

相对S4L，仅将总获取截止从300ms变为360ms（原300ms＋两段各30ms定位）。
从试验开始计时的硬截止，不因重试、部分反馈或等待换向而延长；真正六边沿接管后才退出获取截止。
时间仍包含软件调度开销，因此称“名义60ms定位＋300ms获取”，不是保证精确获得300ms采样时间。

保持：定位每段30ms、每段10ms从210缓升360、获取请求400、首获取相30ms、
常规无反馈22.5ms、救援16/14/12/10/9/8ms、首边沿500µs等待、JEOS与闭环延时算法。
波形记录器保持关闭，小型摘要/保护计数保留。不写参数，不变更原生堵转算法。
延长使失败启动的最大施力窗口增加20%，并不自动更安全；持续无反馈仍须停止，异常电流/剧烈抖动时用户应提前回零。

## 为什么暂不改定位和缓升时间

上一轮13次中6次进入闭环；成功样本既有定位后约7–17ms出现反馈，也有约203ms才出现反馈。
失败样本包括无任何边沿和较晚形成4/5连续边沿两类。没有定位阶段波形或实际转子位置测量，
不能从摘要推断30ms应该加长/缩短，也不能断言10ms缓升太快/慢。这两个参数仍是未校准假设。
本轮先单独检验是否由新增60ms定位挤占获取预算，不承诺能修复零反馈失败。
即使延长后成功率提高，也不证明定位完成；不会据此恢复无限强拉。
