# SINE-FIXED-PROBE：固定矢量100ms与PWM引脚电平核对，未烧录

基于SINE-SENSORS，新增默认关闭FD6288_SINE_FIXED_PROBE，仅允许与正弦隔离/共同平移模式一起启用。

## 预期行为

一次正油门触发固定电角度A150/B269/C29，仍按power6原公式生成CCR3603/3063/3597。A/B MCU高侧PWM下降沿应相隔540ticks=3.375us；这是引脚命令预期，不能要求功率相线因续流/死区也精确呈现同一间隔。无旋转场，不用于测试能否持续起转；可能吸到一处、轻动或不明显运动。自正油门试验开始100ms后关桥，归零/故障可提前停，保持正油门不自动重复。保留原24kHz、2.3us死区、power6、传感器更新和进角设置，不加功率、不改设置页。

## 只读引脚记录

固定PWM写入后至少1ms（跨过多个载波更新），前台最多记录256个CNT前值/PA8..12及PF0输入电平/CNT后值/时间戳，总3096B。不轮询等待，不改GPIO模式/定时器/ADC，不在PWM或ADC ISR内记录。记录满后冻结，未满而提前停止也冻结；记录不决定激励和停机，仅受状态边界控制。短临界区保证停止不会与记录发布交叉；固定PWM由硬件继续运行。

GPIO_IDR用于读数字引脚状态，不是ODR锁存值；可用于AF模式引脚的输入观察，依据[ST RM0440 GPIO alternate-function部分](https://www.st.com/resource/en/reference_manual/rm0440-stm32g4-series-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)。这些是MCU逻辑引脚，不是栅极或相线电压。

后续归零停稳后用本包匹配ELF和tools/scripts/fd6288_native_sine_capture.cjs读取。可选3096B记录两读一致后解析，排除跨计数回绕、读窗口过宽及距切换沿16ticks内的数据；仅在六路AF/输出模式和死区条件匹配时对照PWM1预期。若没有采到三路应不同的窗口，报告覆盖不足，不以“都一样”判故障。完整原始样本保存JSON；控制台只打印分析摘要。

- MCU引脚在应不同的窗口确实不同，且与期望一致：把排查重点下移到驱动器/功率桥和有效电压，不能归咎于软件未写PWM。
- MCU引脚与期望不符：回到定时器/复用/更新路径，保留原始记录判断。
- 采样覆盖不足或配置异常：本轮不作上述归类。

## 离线检查

实际C路径ASan/UBSan验证固定比较值、仅发一次矢量、100ms截止、采样不改PWM、256条满冻结、早停/时钟故障/禁止正油门连续重试。解析器用人工指定的高低电平组合、A/B差异、异常电平、边界/回绕和ABI做检查。原旋转正弦、共同平移和ADC交接回归通过。关闭新开关构建HEX与板上SINE-SENSORS字节相同；ELF/HEX/BIN一致。编译RAM7072B，FLASH代码34204B，保留既有newlib/RWX链接警告。
