# FD6288 G431 启动加力台架版 P1 / 对照 P0

**仅供固定台架测试，禁止飞行。正常起转也会在约 300 ms 后切断驱动，
转子随后自由停转；保持正油门不会自动重试。软件窗口不是硬件限流器。**

尚未刷板或通过实机验收，不是最终版，不替换现有稳定 tag/Release。

## 文件与地址

- `AM32_CUSTOM_FD6288_G431_P1_BENCH_300ms.hex`：本轮首选，短时 +40。
- `AM32_CUSTOM_FD6288_G431_P0_BENCH_300ms.hex`：不加力、同样自动关断的对照。
- `SHA256SUMS.txt`：两个文件的校验值。

两份都只含主固件，HEX 自带地址 `0x08001000..0x0800F7FF`；没有 BL
或设置区数据。只按 HEX 内地址刷主固件，不做整片擦除，不另刷 F800。
引导区仍为 `0x08000000..0x08000FFF`；设置仍为 `0x0800F800..0x0800FFFF`。
此次不改变上电/地面站进入判定，不引入它的超时兜底。

配对调试文件保留在工程的 `obj-startup-power-P1/` 和
`obj-startup-power-P0/`，原始名均为 `AM32_CUSTOM_FD6288_G431_2.20.elf`
及同名 HEX。需要抓数据时必须选实际所刷版本的 ELF，不能用 A/B 的 ELF。

## 改动与设置

P1 在一次合法冷起转中，把当前 startup-floor 请求由 360 提到 400
（内部满量程 2000，名义 18% → 20%），仍经过原有斜坡和保护上限。
保持最多 100 ms，随后 20 ms 撤去额外偏置；若先收到 5 个连续合格
DRIVE 过零，则提前开始撤去。不是加油门百分比，也不是持续提高运行功率。
基于 A 原控制，不合入 B 周期修正，不改相序/过零极性/门极死区/传感器标定。

保留最近已修复的设置：startup_power=150、最低 duty 原始值=1、
固定 PWM 24 kHz、互补 PWM 开，正弦启动/3D/汽车模式/速度闭环关。
对应 RAM：minimum=210、startup_min=360、startup_max=610。
不兼容的设置会拒绝起转，不会偷偷写 EEPROM。方向保持当前已确认正确的值。
第一轮保留此前堵转保护关闭的状态，暂不同时更改其他参数。

原生堵转保护的开关、超时阈值、计数及锁止规则未改，也没有延长其预算。
启动加力可能间接改变过零/超时，因此仍不能宣称堵转保护已好用。
300 ms 结束单独记为 `window_300ms`，原生保护触发记为 `native_stuck`。

台架版不允许 Coast 旋转接管：每次回零且**等转子完全停稳**，再开始下一次。
不要用这个测试版检查空中救援/旋转重启或持续转速。

## 测试步骤

1. 刷入前油门回零，确认转子完全停稳。先卸载检查启动音、地面站和遥测。
2. 先做一次卸载短起转，确认约 0.3 秒后切断驱动；正油门保持不重启。
   如果未切断、抖动、声音异常或电流异常，立即人工回零并停止该轮，
   不为等待窗口结束而维持异常。随后确认回零、停稳后可再次起转。
3. 上述关断行为确认后，才在已有固定、防护的台架上恢复相同负载。
   保持原来的油门缓升方式和目标约 20%，不要突然打满；300 ms 窗口
   测的是最初起转，不要求一定达到 20% 对应稳态转速。
4. 先做 5 次，记录顺畅/抖动、方向、是否按时切断，有无异常电流或温升。
   每次回零并等完全停稳，电机/电调若温热先冷却，不连续硬试卡转。
   再决定是否扩展到 10 次或换 P0 做同条件对照。
5. 如要读取摘要，最后回零停稳、保持供电、不重启；否则 RAM 记录消失。
   摘要保留最近 16 次，详细采样块只保留首次，后续精抓须单独重新准备。

同设置下的一小组成功不能证明偶发故障消除；若只是电流增加而仍无法
获得有效过零，停止加功率，继续分析预定位/开环起转及接管时序。

## 构建与离线核验

只构建一个板型，不运行 `all`：

```sh
make -j1 CUSTOM_FD6288_G431 OBJ=obj-startup-power-P1 ARM_SDK_PREFIX=arm-none-eabi- FD6288_STARTUP_TRACE=1 FD6288_STARTUP_TIMING_FIX=0 FD6288_STARTUP_POWER_BENCH=1 FD6288_STARTUP_POWER_EXTRA=40
```

P0 改为 `OBJ=obj-startup-power-P0`、`FD6288_STARTUP_POWER_EXTRA=0`。
普通构建默认 BENCH=0；必须使用不同输出目录，避免 Make 复用旧变体。

离线验证：策略 3883 条、实际函数 A 474 / B 488 / P0 226 / P1 226 条；
ASan/UBSan 通过。捕获工具的假 RAM/RPC、设置/地址/镜像身份检查通过。
HEX 校验和、向量、名称地址、BIN/HEX 一致性、BL/F800 无数据均通过。
RAM 链接占用 28408 B/32768 B（含链接脚本预留区），不是运行时栈峰值测量。
普通关闭实验的 A 与此前 A 字节一致。尚未测实机服务延迟或门极波形。
