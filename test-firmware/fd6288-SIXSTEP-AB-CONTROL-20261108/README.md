# A→B六步定位通路对照，100ms

仅将当前A→C正对照的step6改为step1：A相互补PWM不变，B相持续拉低，C相浮空。24K、请求360/2000(18%)、compare1200、2.3us死区、单次最多100ms和全部停止/保护边界不变，不发车。不是持续起转测试。

目标：当前A→C已记录0.04A静态、0.81A过滤峰值和明显吸动，但B浮空；前面固定正弦的A/C几乎同相，主要通过B回流。该对照单独检查B返回通路在GPIO持续拉低方式下能否同样建立明显电流与定位。通过后仍不能替代B低侧在三PWM切换下的验证。

保留同一40B约1ms传感器基线/过滤峰值/原始ADC最高/母线最低摘要、80B配置和3096B引脚记录。读取器按summary.last_step选择step1或step6预期，不能从已测GPIO电平反推命令而掩盖错误。两种模式的MODER相同，真正不同的是B低/C低的逻辑状态，因此必须同时检查实测电平。B功率端本版应接近电源负极，C浮空；A仍PWM。

程序18%是定时器给定，实际相线高电平还受死区、续流和电流方向影响。正弦的对地约50%含共模，不能与六步的单路18%直接比较为功率强弱；旧step6里的B浮空波形不是受控占空比。

实际C/comStep/phaseouts在ASan/UBSan下通过：A PWM/B LOW/C FLOAT，一次关桥预装载更新，100ms、归零/失能/时钟/错误周期/保护上限停止，传感器和引脚冻结。step1/6解析器及缺失低侧检测通过；原step6回归通过，关闭新开关强制完整构建HEX与当前step6包逐字节相同；ELF/HEX/BIN与读取符号核对通过。未实测，构建日志保留既有newlib/RWX警告。
