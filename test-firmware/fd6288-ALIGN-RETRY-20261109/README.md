## 本版行为

- 正常启动沿用ALIGN—PAIR的30ms第一定位＋300ms第二定位，定位占空比/首发矢量/前侧与预期方向资格/ADC一致性/实际死区/5us切桥关断/TIM16调度保留。
- 正常首个ADC合格反馈立即采用，仍只等待原500us后换相；第2..5反馈按原时序，第6个实际可用反馈及实测延时才接管运行。不会强制首发等满30ms，不做<=1ms早事件补激励。
- 首发最多等30ms；接受首反馈后，后续启动等待扇区最多22.5ms。缺反馈就判当前轮失败，不盲走下一个矢量或耗旧六步救援预算。
- 失败时全关六管、取消异步换相、清占空比和本轮反馈历史；关断完成后等待100ms，再从同样的第一定位矢量开始完整30＋300ms定位及首发。方向不变，不旋转重定位种子。
- **总共最多3轮，包含首次，等于最多2次自动重启。** 每次真正启动失败增加失败计数，部分反馈/重新定位均不清零；计数器也不用于伪造过零。原堵转与故障锁存不通过重启清除。
- 每轮从定位开始最多630ms，整个获取过程从首次定位起最多2090ms，预算不随反馈或重试续期。若三轮都完全无首反馈，通常约1280ms便停止，而不是必须耗满2090ms。软件服务截止，不是硬件独立切断定时器。
- 次数/期限耗尽后锁止，持续正油门不会开始第四轮；归零才允许新的启动。归零、解除武装、保护故障优先取消；正常运行后丢反馈仍停机，不自动重启。
- 接管成功后进入完整运行，**不再100ms自动停机**；2.09秒只限制启动获取，不限制成功后的运行时长。

这次不缩短300ms定位，不修改首发功率/进角，不引入正弦分支的新PWM分配。参考Bluejay的是“失败后关断等待、有次数上限、完整重启”的结构，不是移植其首步强制超时规则或声称参数完全相同。
