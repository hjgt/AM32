# S4D：单个过零后的有限短扇区衔接

2026-09-23，variant 14。已生成、未烧录、未实测。仅供限时台架对照，不能飞行。
板上仍是 S4C；本轮未操作仿真器或改变设置。

## 修改与证据边界

S4C 第 7 次在快速试探中收到一个边沿，下一扇区再无连续反馈。
剩余一段 8 ms 额度被取消，回到 22.5 ms 超时。
S4D 假设：保留短扇区余量可能帮助建立连续反馈，而不是在孤立
边沿后立即退回较长等待。**这是待实测的控制假设，不是已确认根因。**

- 单个有效过零仍立即引导换相；若在试探中，消耗当前一段，剩余
  短扇区额度继续有效。边沿和超时都会消耗额度，不因边沿补回。
- 连续第二个有效过零取消全部余量，恢复原事件引导流程。
- 六段总额度不增加、不重发。用完后仍为 22.5 ms 超时；尚未开始
  试探时的逻辑和 S4C 相同。闭环丢反馈仍立即停止，不重启试探。
- S4C #10 在第六段才出现首边沿，已无余量，所以此改动对它的
  此处处理不生效。不能承诺解决全部失败，也不延长时间掩盖失败。
- 功率 360/400、接管下限退出、ADC 预侧/迟滞/确认/早期拒绝、
  六个连续边沿才接管、300 ms 获取截止和 1 s 观察均不变。
- 原生堵转代码/设置未修改，所有超时继续计数，故障优先于换相。
  时序变化可能改变实际触发频率；堵转保护仍未获实机可用结论。
- BL、F800 和地面站入口不变。
