# NATIVE-SINE：独立初始化控制时钟，2026-11-08

已构建和离线检查，**未烧录**。本包取代已撤回的 NATIVE-SINE-INHERIT-TIMING。
后者在关闭记录器时漏启用 DWT，不能正常执行依赖该时钟的反馈延时和试验截止。
这项缺陷由板上只读寄存器检查确认，不能据该轮判断原生正弦启动路线失败。

## 修复

- 在外设中断启用前，独立启用 DEMCR.TRCENA 与 DWT.CTRL.CYCCNTENA。
- 启动时检查 CYCCNT 确实推进；计数器未运行时拒绝输出。
- 输出和服务路径也检查控制时钟使能，失败时关桥锁止，需真实回零。
- 不依赖波形记录器的初始化。没有增加 ADC 转换、日志缓冲或调整驱动参数。
- 只读摘要工具同时记录 DWT 状态；时钟失效时将毫秒字段标为无效，保留原始计数。

配置仍为150%、900KV、14极、正弦开启、range15、power6；进角和自动／手动模式
继续继承保存参数。原始设置备份与恢复文件保留。正弦与六步交接代码不改。

`AM32_CUSTOM_FD6288_G431_2.20.hex` 仅主程序；`NATIVE-SINE-COMBINED.hex`
为主程序＋相同配置页，不含 Bootloader。修复后预期整次最多3秒、六次真实反馈后
最多再观察1秒；上板复测前必须确认 DWT 实际推进，不能再仅凭离线测试声称截止已生效。

新增回归从未初始化的时钟状态开始，覆盖未启用、使能但不计数、运行中失去时钟三种
拒绝输出情形，并检查 main 的初始化钩子先于外设中断启用。实际 C 控制和 ADC 链路
测试通过 ASan/UBSan，BIN/HEX 与配置封装检查通过。硬件计时和电机效果尚待新一轮验证。
