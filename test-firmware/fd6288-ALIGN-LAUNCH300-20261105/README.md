## 行为与参数

- 回到ALIGN-PAIR + PB7的正常启动路径，FD6288_ALIGN_ONLY=0，FD6288_SECOND_ALIGN_MS=300。第一定位30ms，第二定位300ms，约330ms进入原首发矢量。
- 原定位占空比渐升/保持、首发矢量、换相前5us关断、前侧资格、FIRST500、ADC一致性及TIM16调度保留。没有新增电压补偿或改变EEPROM设置。
- 仍沿用基线的一次有界重定位/重试。为保留每轮定位后的原300ms获取窗口，第一轮截止从390ms改为630ms，允许重试入口从390..410ms对应移至630..650ms，两轮总截止从820ms对应改为1300ms。重试定位也使用30+300ms，次数不增加。健康接管后沿用原运行流程，归零停机。
- PB7恢复正常启动语义：约330ms首次发车桥配置完成后拉高，下一次换相或关断时拉低；不再是长观察版90..330ms保持标记。
- 原定位bins仍只记录首30ms和第二定位最初60ms，即原0..90ms窗口；没有记录第二定位最后240ms，不把这些bins称为本版定位末段。早晚配对窗口仍为第二定位10..55ms。

## 用户确定的测试顺序

1. 先用本版判断较稳定的300ms定位后能否正常接上启动。区分首发直接顺滑接上、后续咔咔/重试后才起转和不起转，记录是否改变初始位置。
2. 若本版跨不同初始位置能顺利接上，回到不发车诊断模式，逐步缩短第二段，以肉眼收敛现象找范围。采用用户建议，不用高成功率的启动试验逐档追稀少失败。
3. 用户指出第二定位期间存在电池压降；后续记录供电条件及可取得的电压。相同占空比不等于相同电流/转矩，未同步电压时不将表现变化全部归因于时长。
4. 诊断模式找到候选时长后，再回启动版做必要确认；诊断停稳不直接等于启动已验证。
