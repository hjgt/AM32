# S1：受控冷起转实验，300 ms 台架版，禁止飞行

这是替代 P1 小幅加力测试的**未上板验证候选**，不是稳定版或最终版。
仅用于固定、安全隔离的短时台架；不能把自动停止误当成普通工作模式。
本轮没有连接调试器、读板、刷新或起转。

## 文件和地址

- `AM32_CUSTOM_FD6288_G431_S1_BENCH_300ms.hex`：主区 `0x08001000..0x0800F7FF`。
- 不包含 BL `0x08000000..0x08000FFF`，不包含设置页 `0x0800F800..0x0800FFFF`。
- 不重刷 F800，不改地面站入口，不改 EEPROM 布局。
- HEX SHA-256：`aff95a6d70a20d889a1f3a0b04df4bbaf3bcbfb35ed791bf12982d203da7b5b3`。
- 配对 ELF：`obj-startup-sequence-S1/AM32_CUSTOM_FD6288_G431_2.20.elf`，本地保留用于符号采集。
- 单目标构建命令见 `tests/README.md`；不要编译全部 target。

## 改了什么

1. 冷起转统一从物理第 1 相位矢量定位 30 ms，不沿用上次失败留下的相位。
2. 开环六步换相从每扇区 12 ms 开始，每步缩短为 15/16，最低 4 ms。
   延迟调用只推进一步，不突发补齐；整个台架窗口最多 300 ms。
3. 定位占空比请求 360，开环请求 400（AM32 0..2000 单位，含既有补偿）；
   不随高油门抬高开环请求，仍经过原有斜率、电流/温度等限制与 C06。
   接管后 +40 下限在 20 ms 内退回原下限。不是新的 ADC 最小占空比。
4. ADC 原有鲜样本、消隐、有效 ON 窗口、迟滞、前态/后态确认保持。
   开环计时基准是“命令换相”，因此暂停闭环的“上次过零半周期”门限；
   用每扇区 1/8..7/8 位置窗口、相邻边沿周期 3/4..5/4 一致性检查替代。
   要有连续 6 个相邻扇区合格边沿才能接管；缺失/不合格会打断连续计数。
5. 接管等到真实过零后的半周期减提前量，而非收到边沿就立即换相。
   用真实边沿周期初始化闭环计时、历史与过零计数，不把计划步进算过零。
6. 保留原生堵转开关、运行期计数/阈值和故障锁定；启动计划步进不算超时。
   启动超预算即便开关 Off 也停止，正油门不自动重试，必须回零。
   当前成功也会在 300 ms 停止，不能用它验证长时间运行或飞行保护。

30 ms、12→4 ms、连续 6 次、360/400 都是本次待验证实验参数，不是
已经确认适合此电机/桨叶的定值。定位可能有短促机械摆动；不代表方向检测。
软窗口也不是硬件限流或相电流保护。

## 记录与最少测试流程

S1 使用 variant=4。保存最近 16 次摘要，以及**首次被固件判失败**的详细
trace：未接管、接管后有超时、原生保护/安全停机等。正常 trial 的详细记录
会在下一次起转时覆盖，失败记录保持到显式停止态 ARM 或重启。
提前人工回零记作 operator_zero，不自动归类为启动失败；不要仅凭 closed_loop
字段宣称机械转动正常。摘要 first/fifth 是 ADC 接受时间，不是六边沿接管时间。
采集时看 `capture_id`，不能误认为一定属于最后一次测试。

首次刷新后，先卸载确认方向、300 ms 停止和零命令恢复，再进入用户已准备的
安全固定带载条件。冷起转之间必须回零、转子完全停稳。不要为了凑次数
持续抖动加油；发现异常温升/大电流立即回零断电。不要用手堵转。
一次小批量后回零停稳、保持供电，统一读最近摘要及保留的失败记录即可。
如果要改堵转保护设置导致重启，**先抓取这一批 RAM 记录**，否则会丢失。

正常迭代沿用既定效率约定：停止确认、仅主区写入、一次写入校验、简短
运行态检查；不重复完整旧固件备份和新固件全区回读。需要新鲜的停止确认
才可刷入，本 README 不授权自动操作硬件。

停止态、已确认配对固件的只读抓取（不要在旋转中执行）：

```sh
node tools/scripts/fd6288_startup_capture.cjs dump obj-startup-sequence-S1/AM32_CUSTOM_FD6288_G431_2.20.elf NEW-S1-TRACE.bin --stopped --quick-dump
```

抓取工具不会 halt/reset、启动电机或写 Flash；S1 已自动准备新 trial，通常
无需手工 ARM。`--quick-dump` 只检查选定身份字节，不冒充全镜像验证。

## 离线结果

- A/B/P0/P1/S1 函数回归与 ASan/UBSan 通过，S1 12626 条断言。
- P0/P1 纯策略回归 3883 条断言通过。
- 仅构建 `CUSTOM_FD6288_G431`；S1 RAM 28440 B，HEX 有效数据 34460 B。
- HEX/BIN 一致，主区地址/校验和/向量/固件名检查通过。
- 新功能关闭后的 trace A 对照 HEX 与原 A 逐字节一致。
- 采集工具通过模拟内存/RPC 回归；没有物理电机、功率级或全中断时序仿真。
- 链接仍有现存 newlib 系统调用桩及 RWX LOAD 段警告；本轮未改链接布局。
