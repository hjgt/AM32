## 与旧记录器的区别

- 不再各锁住第一次成功/未锁定/闭环丢反馈；**每次启动覆盖上一条详细波形**。另有原16条启动摘要仍保留。
- 保存从本次启动起的前1280组软件消费的ADC数据，不作100/400µs抽样、不在首次过零后冻结。24kHz下约53.3ms，覆盖30ms首相与22.5ms第二相，第三相仅开头；不是完整300ms。
- 1280组之后只更新计数，绝不覆盖前缀；事件保存前48条并报告省略数量。
- 每样本16字节：软件记录时间、三相ADC、PWM/触发比较值、相序、判决原因、前侧见证、确认次数、方向和阶段。确认次数饱和至7。
- 无效/屏蔽/未武装等软件判决样本同样保存；换向时已清掉或硬件未转换的数据无法恢复。JDR读数不是示波器波形，CCR读取也是当前预装载值，不是采样时刻锁存值。
- full-rate只指不再抽样丢弃**已进入记录器**的样本，不保证硬件每次转换都被消费。日志开销须通过实机irq_max_us等再检查。

ABI3布局：64字节公共头＋64字节单次头＋1280×16字节样本＋48×20字节事件=21568字节。命令写入仍只拒绝，不提供远程起转。
