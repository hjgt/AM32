## 唯一控制变化

- 收到有效过零，仍立即按反馈换相，取消正在进行的试探，并清零
  “连续无反馈扇区数”。**收到边沿本身不再消耗尚未使用的额度。**
- 此后若尚未接管，又连续两个 22.5 ms 扇区收不到有效过零，且
  试探额度没用过，则执行一次最多六段 8 ms 试探。
- 只有实际进入试探才把额度标记为已使用。若中途获得有效过零，
  立即退出，剩余段数作废；以后即使再次丢反馈也不续用、不重来。
- 间歇出现有效边沿会重置连续失联计数；不累计零散超时来误触发
  试探。原生堵转超时计数是另一份计数，**不因这里重置而清零**。
- 已接管、已停机锁存或已经用过额度时，不触发此后备流程。只有
  真实回零后允许的新启动才重新获得一次额度。

按 #3 的事件顺序取整回放：先两边沿、一次超时、再一个边沿，
随后两次连续无反馈，新逻辑约 107.1 ms 就进入试探，旧逻辑始终
保持 22.5 ms。这证明机会不再被提前取消，**不证明物理电机必会
转起来**，也不是重放后半段机械轨迹的电机仿真。

## 保留的边界

获取阶段总截止仍为 300 ms，临近截止也不会为了完成六段而延长；
接管后仍最多观察 1 秒。真实回零/安全限值/原生故障锁存优先。
每个缺失反馈的试探仍计入原生超时，不能伪造真实边沿或换相成功。
开启保护时，新增机会可能让原生超时更快累积，触发行为需实测；
开关、阈值、计数和锁存代码本身不变，不能把台架截止当保护验收。

原 S4B 的最新真实周期交接、ADC 预侧/极性/迟滞/确认/early 拒绝、
首次换相延时、360/400 出力、150–450 ms 下限退出、采样窗口及
实际死区不变。BL/F800/地面站入口/设置布局不变，不增加启动兜底
入口超时，不把此次改动扩展到闭环掉反馈后的盲目重启。
