# S4B：只修正接管时最新真实周期的初始化

2026-09-23，variant 12。**已生成、软件验证通过，未烧录、未实测；
仍是限时台架版，不可飞行。** 本轮未连接或操作电调。

## 原因与修改范围

[S4 首轮 17 次证据](../../hardware-backups/startup-S4-20260923/README.md)
中，15 次完整观察，#8/#17 在接管后的第一个候选过零被 early
拒绝，之后持续 unarmed 并超时。两次最后真实边沿间隔约
6.732/6.631 ms，但门限初始化使用了平滑的 12.2925/10.6155 ms。

S4B 只增加独立 `last_real_period`：

- 第二个及后续连续真实边沿更新它；首边沿没有周期，保持零。
- 重试超时/新启动清零，不能带入上次获取的数据。
- 六边沿接管时，只将这个最新真实相邻边沿间隔传给 ADC 检测器。
- 检测器原来的 `min(平滑周期, 最新真实周期)/2` 公式不变；不直接
  调低固定系数、不取消门限、不在时间过去后自动认可早期脉冲。

基于记录，#8 的门限将从约 6.146 ms 变为约 3.366 ms；#17 从约
5.3075 ms 变为约 3.3155 ms。5.961/5.298 ms 的候选不再仅因
加速阶段 IIR 滞后而被时间门挡住；仍须满足预侧、迟滞和确认规则。
这不是保证候选全部为真实反电势，最终效果必须实测。

**不改**平滑周期自身、第一次接管换相的延时、周期滤波、S4 的
360/400 功率、一次性短时试探、150–450 ms 下限退出、ADC 采样
窗口、极性/预侧/确认条件、故障锁存或原生堵转计数/开关/阈值。
保持 300 ms 获取、接管后最多 1 秒观察、闭环首次超时即停止。
BL、F800、设置布局、地面站入口、桥相线映射及实际死区均未改。

首次换相延时仍使用平滑周期，这是刻意保留的相邻变量。如果剩余
失败仍与交接相关，再用记录判断，不在本次同时改掉以免无法归因。
检测结果改变可能影响保护触发频率；软件测试不能代替堵转实机验收。

## 验证

- 实际 C 代码 ASan/UBSan：S4B 83223 个断言通过。保留旧版本回归，
  新增按 #8/#17 加速间隔（取整 µs）的正反方向回放：S4 原逻辑
  拒绝候选，S4B 经两次确认接受；平滑周期/首次换相延时不变。
- 检查零初始化、首边沿、超时清除、计数器回绕；真正早于门限的
  脉冲仍会清掉预侧状态，门限过去后不能冒充新过零。
- 三槽记录器/解码/停止态只读采集模拟通过，variant 12 明确标记
  新行为；保留旧版本解码。三槽容量和结构未改。
- target 选项组合、BIN/HEX 一致性与地址范围、ARM 事件日志代码
  检查通过。原有 newlib/RWX 链接警告未新增。

这不是物理电机仿真。回放证明软件边界行为变化，不能证明剩余
两次故障在实机必然消失，也不意味着能飞。
