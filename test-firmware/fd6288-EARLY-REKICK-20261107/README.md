## 行为

30+300ms双定位及原功率保留；正常首事件按原资格和500us延时换相，随后原2..5即时换相、第6次实测延时/六可用事件接管不变。不再强制首发固定30ms。

仅当每次首发脉冲的第一个ADC合格事件，距实际施加首发后软件重锚时刻<=1000us，才把它作为诊断恢复触发：该事件不记为可用过零/周期/连续反馈；立即关六管、取消异步换相、占空比归零，保持20ms全关断，再用原5us切桥间隔、原首发矢量重新激励。正转重复step2，反转重复step6，不是推进到下一矢量，也不重新跑300ms定位。

最多补3次，连初次共4个脉冲。第四个脉冲再出现<=1ms首事件就关断停止，没有第4次补激励。任何一个脉冲首事件>1ms，则立即走原反馈接续，此后其他矢量的短间隔不会再次触发首发异常分支。

1ms/20ms是本次诊断档位，不是已确认的假过零门限或生产参数；早事件也曾出现在可成功样本中。效果须实测。

## 停止及范围

没有合格首事件则当前脉冲30ms截止；正常接续后任一等待扇区22.5ms无事件也停止。**这些普通超时不消耗补激励次数，不触发补激励；旧救援步进、100ms三轮重试和旋转重定位均不使用。** 因此正常反馈时序恢复原路，但本版不是恢复旧的全部超时救援行为。

整轮启动获取从初次定位开始630ms软件截止，任何补激励不续期；630ms内最多增加3个20ms释放间隔，保护/归零始终优先。达到上限/故障后保持正油门不能继续尝试，必须先归零再开始新trial。正常接管后的反馈丢失仍立即停机，不自动恢复。软件截止不是独立硬件定时切断。
