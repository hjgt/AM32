# SINE-CENTERED：仅正弦输出映射修正，尚未烧录

基于已刷 SINE-ONLY（06ab1bf）。仍是 power6、150% startup 配置、原生角度/速度映射和3秒上限；不进入六步，不改进角、不改硬件死区，不写参数页。

旧输出CCR139..859，板上实测DTG0xce、CKD DIV1意味着368ticks死区。依STM32G4 RM0440，短于死区的脉冲不生成；实际公式每相137/360个角度落入该区间。本修正将三个CCR共同平移，使最小/最大围绕周期中间对称，保持每一对CCR之差完全不变。逐角度验证输出3020..3646ticks，高/低间隔均远超368ticks。

注意这是共同平移比较值，定时器仍是原先的边沿对齐PWM；不是切换到中心对齐计数模式，也不是提高正弦幅值。使用UDIS保护三个预装载比较值的成组更新，不清CNT、不发UG。异常分频/死区/更新配置拒绝输出。

新增80B最后驱动态快照，仅停机前读一次TIM1/GPIO/角度状态，不在PWM或ADC路径连续采样。只读脚本自动识别该符号；用本包匹配ELF。快照不是电机电压/电流或转速测量。

构建与离线检查见build-args.json、verification.json；关闭新开关所得HEX与已刷SINE-ONLY字节完全相同。主程序仅占FLASH约30.9KB，无EEPROM段。编译通过，保留既有newlib syscall/RWX链接警告。

**本包未烧录、未实测。板上仍是旧SINE-ONLY。** 不能将离线检查当作电机已恢复；此次也未提高功率、改动死区或发送油门。
