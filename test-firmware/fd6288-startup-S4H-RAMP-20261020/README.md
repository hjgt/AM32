# S4H-RAMP（variant22，2026-10-20已烧录）

基于 S4G-NOEDGE，只调整一次性补救的六段换相间隔：
固定 8/8/8/8/8/8ms → 16/14/12/10/9/8ms。
这些是待验证的实验值，不是已测定的转子加速轨迹。
目的：降低两次22.5ms无反馈后突然进入8ms节奏的变化幅度。
不恢复S1定位/S2强拉，不增加功率，不改变直接反馈起转路径。

总盲拉预算由48ms变为69ms，但只用一次六段预算，整体300ms未锁定
截止不变；不得视为相同热负荷。孤立边沿仍消耗本段，下一段等待22.5ms，
超时后按剩余预算继续斜坡，不从16ms重新开始。第二个连续边沿取消
剩余补救。首边沿500us、后续相位延迟、六边沿接管、ADC资格不变。
正常闭环无1s自动停机；测试结束主动回零。

原生堵转保护代码/阈值不改，每次真实超时照常计数；超时节奏会变化，
因此原生保护的时间响应仍需验证。本版不是可飞或堵转保护验收版。
