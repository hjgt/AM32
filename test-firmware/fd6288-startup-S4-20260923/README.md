# S4：零反馈短时试探 + 闭环出力平滑交接

2026-09-23，variant 11。**软件验证通过，未烧录、未实测；限时台架版，不可飞行。**
本轮没有连接、暂停、复位或写入电调。板上最后确认的固件仍为 S3-DT。

## 依据与假设

S3-DT 十次为 3 次完整观察、3 次未接管、4 次接管后丢反馈。
[原始证据](../../hardware-backups/startup-S3DT-20260922/README.md)保留在本地仓库。

1. 未接管 #2 全程零个有效过零、13 次 22.5 ms 试探。用户补充这些
   “零有效过零”的失败肉眼表现为原地抽搐，压根没有持续转起来。
   这支持先研究建立连续转动，而不是假定电机已经正常旋转仅漏检。
   仍不能从这条描述区分初始角度、负载/力矩、换相节奏、退磁或 ADC
   模拟时机；不能把正向/反向检测电压跨越等同于机械转向。
2. 接管后失败 #1 在连续第 30→31 边沿之间 duty 360→277，之后
   ZC 服务间隔从约 3 ms 拉长至约 20 ms。代码的三十边沿门槛确实
   对应下限撤除；物理因果及其他失败是否相同仍需试验。
3. S3-P 的 540/600 出力试验未改善且电流更高，所以 S4 不继续加
   获取功率。两类问题合并进入一个实验版本，是用户明确要求；
   不能据合并试验的总成功率单独证明每一处改动的效果。

ST 的[六步启动说明](https://www.st.com/resource/en/application_note/an4220-sensorless-sixstep-bldc-commutation-stmicroelectronics.pdf)
讨论了静止时缺少反电势信息、需要先建立转动再进入同步换相的限制。
这只是路线依据，**不是本板 8 ms、150 ms、300 ms 参数的实测依据**。
这些值都是此次有界实验参数，不是已验证的电机额定值或通用最优值。

## 修改一：只对“始终没有有效反馈”增加一次短时试探

- 开始仍是 S3 的同一物理矢量、同一方向映射、同一 360/400 请求；
  先保持两次 22.5 ms 的无反馈等待。
- 只有前两次都没有获得被启动策略接受的真实过零，才把后续最多
  六个扇区的无反馈等待缩为 8 ms，名义合计 48 ms。随后回到
  22.5 ms；一次油门启动内不再重复这段试探。
- 任一扇区收到有效过零，立即取消/禁止这段试探，按 S3 反馈驱动
  后续换相。已有一个孤立有效过零、随后又丢反馈的启动，不启用
  这项“零边沿”试探。
- 仍需六个连续合格过零才能接管；固定时间换相不增加真实过零
  计数、不更新闭环周期滤波。预侧、极性、迟滞、确认次数不放宽。
- 与 S2 不同：没有贯穿整个获取期的固定加速表，不等待预定时刻
  才响应有效过零，不沿用 S2 的扇区相位窗口。8 ms 只是无反馈
  的等待上限，不是测到的电机周期，也不代表转子真的跟随。
- 延迟服务最多执行一次换相，不追赶连发；300 ms 总获取截止不变。

对于“长时间停留在某矢量，只拉一下/往复抽搐”的假设，这提供一次
建立连续运动的机会。但若实际需要更长定位/更慢牵引，8 ms 也可能
更差；试验失败不能继续随意放宽过零或不断加功率。

## 修改二：启动下限不再由三十边沿直接撤除

- 获取阶段仍为前 30 ms 请求 360，随后 400（0..2000 duty 标度，
  不是瓦数或实际力矩，且仍经过原斜坡和安全上限）。
- 接管初期保留 S3 原来的 400→360、20 ms 过渡（从第六边沿计时，
  前 30 ms 请求仍不超过 360）。
- 之后保持 360 下限至接管后 150 ms，再用 300 ms 把下限平滑降向
  当前 minimum_duty_cycle=210；到接管后 450 ms 完全释放下限。
- 第 30 个过零不再取消这个时间包络。例：正常油门映射为 277 时，
  实际请求为 `max(277, 当前下限)`，无需从 360 直接落到 277。
- 这只是下限，不压低更高的正常油门请求，也不延长原 610 启动
  上限的生效条件。真实回零停止、输出斜坡、电流/温度等安全上限
  的优先级不变。没有依据转速反馈自适应选择退出时间。

## 堵转保护与其他边界

原生堵转开关、计数阈值、故障锁存、真实回零才能解除的逻辑未改。
**每次 8 ms 无反馈试探仍增加原生超时计数，绝不把试探假装成正常过零
或清掉故障计数。** 因此启用保护后，触发时间可能提前。以初始计数
0、阈值 10、始终无有效边沿且服务及时为例，第 11 次超时名义从
S3 的 247.5 ms 提前至 S4 的 160.5 ms；真实调度会有延迟。
这是已知行为变化，不是“保护完全不受影响”。

300 ms 未接管自动停止、接管后最多 1 秒观察、闭环第一次超时即
停止仍保留。锁存后不在正油门下自动再起转，必须真实回零。
这些台架停止不能代替原生堵转保护的物理验收，也不是硬件限流器。

保持 S3-DT 的 ADC floor=460、minimum ON=704；不改变实际 DTG=0xCE、
桥相线映射、死区补偿 200、BL、F800、地面站入口或 EEPROM 参数。
**没有添加上电入口超时兜底。** 不涉及 RF 前向编程。

## 软件验证及局限

- 实际 C 的 ADC/换相/故障/台架代码：旧 A/B/P0/P1/S1/S2/S3/S3-P
  回归通过，S4 83072 个断言通过 ASan/UBSan，包括正反方向、一次性
  试探、任一阶段有效边沿取消、超时边界、DWT 回绕、无追赶突发、
  三十边沿处出力、平滑单调退出、真实回零、安全限制和原生锁存。
- 出力算术用独立 64 位参考覆盖 0..2000 范围，避免 raw DWT 周期
  直接乘 duty 差值溢出；实际输出分支而非仅公式经过测试。
- 原三类波形记录器、C→JS 解码和停止态只读采集模拟通过；没有改变
  三槽大小/ABI，新增 variant 11 和 S4 说明。旧变体仍可解码。
- 原 ADC 窗口/C06 测试覆盖全部 256 DTG 编码、65536 脉宽以及
  9001 ARR 的安全上限边界。实际 target 编译选项组合检查通过。
- BIN/HEX 数据一致、地址范围通过；ARM 事件记录函数没有函数调用、
  bulk-copy 或栈临时数组。已有 newlib/RWX 链接警告未新增。

以上不是物理电机仿真，不能证明带载起转、电流峰值、机械方向或
实时裕量。必须保留“候选、未实测”的状态。

## 下一轮最少测试及读取计划

1. 先保持现有设置（原生堵转 Off）及相同电池/负载/油门上升方式，
   首批最多 5 次；每次真实回零并停稳。明显异常电流/发热或卡顿
   立即回零，不为等记录硬撑到截止。不手拨带电转子、不人为堵桨。
2. 没有新的危险表现时补至总计 10 次，记下各次“顺利转起 / 原地
   抽搐 / 转起后失速”。正常接管后约 1 秒的自动停止是台架设计。
3. 最后一轮回零停稳后保持供电，勿重启，读取最近 16 次摘要与首个
   未接管、首个接管后丢反馈、首个完整观察三个独立槽。
4. 重点查：零边沿类是否减少，45 ms 后短试探是否出现有效边沿；
   第 30 边沿是否不再掉出力；150–450 ms 退出期间是否再次失速；
   电流/最低电压、超时原因和记录耗时是否恶化。比较变化不是宣称
   十次足以证明可飞；同时修改两处需要按失败类别分析。
5. 起转可靠性明显改善后，再单独约定原生堵转 On 的正常起转验证。
   不把开启成功等同于真实堵转保护验收，不进行人为带桨堵转测试。
