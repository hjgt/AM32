# S4E：反馈独立等待，接管后手动停机

2026-09-24，variant 17，已生成未烧录。用户接受：保留 300 ms 未接管
停机，只取消接管后的 1 s 自动停机，旅行前最后一轮测试后暂停。
**本版不是飞行最终版，也不是已验证的原生堵转保护版本。**

## 控制变化

S4D-EDGE #4 首次接受后下一扇区持续负侧，8 ms 到期被强制换相；
成功 #1 的下一扇区在前约12 ms也仍为负侧。等待过短是线索，
不是已证实根因；首个快速边沿仍可能含换相/电流暂态。

S4E 将“盲试探8ms”与“收到首个有效边沿后的等待22.5ms”分开：

- 首边沿仍立即按原流程换相，消耗当前短扇区额度，下一扇区最多
  等22.5ms真实反馈。不用该孤立边沿距换相的约0.5ms当机械周期。
- 若等待超时，继续原生超时计数、清连续计数，消耗当前已有额度，
  只恢复剩余8ms试探；总六段额度不增加，不重复发放。
- 连续第二边沿取消剩余额度，后续六边沿接管条件与检测门限不变。
- 与S4C不同：首边沿不永久丢掉余量；与S4D不同：不要求后继边沿
  在8ms内出现。不是简单恢复一个已有版本，更不保证物理成功。

## 停机与记录边界（重要）

- 未接管仍在300ms截止，不能靠保持正油门自动重试。
- 成功接管后**不再1s自动停机**，需操作人主动回零。
- 接管后第一次反馈超时仍停机；原生故障/安全上限/回零处理保留。
- 原生堵转开关和设置未改，当前最近读到的是关闭，不能宣称已验证。
- 诊断仍只观察接管后1s，随后冻结波形/摘要指标而不关电机，防止
  DWT长时间回绕与统计溢出。启动下限在既定退出后不因回绕重新出现。
- 最终摘要的停止原因可晚于冻结窗口：elapsed、电流最大值、接受/
  超时计数仅代表记录窗口，不是整个长运行的统计。1s后故障仍能
  停机并记录最终原因，但不保证有该故障的波形。必须停稳后读取。
- 保留S4D-EDGE的首次边沿100us定点波形与12ms后窗口；不修改BL/
  F800、PWM死区、ADC检测门限、功率360/400或地面站入口。
