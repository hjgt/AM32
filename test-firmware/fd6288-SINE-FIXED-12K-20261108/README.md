# SINE-FIXED-12K：固定矢量100ms载波对照，尚未烧录

## 本版与当前板上24K固定矢量的差别

仅改变物理驱动的载波：24kHz→约12kHz；固定电角度A150/B269/C29、power6、2.3us死区、单次100ms、归零/故障提前关桥与禁止正油门持续重试均沿用。无旋转场，不用于持续起转测试。本版是诊断对照，最终48K目标未改变。

| 项目 | 板上24K | 候选12K |
| --- | --- | --- |
| ARR | 6665 | 13330 |
| CCR A/B/C | 3603/3063/3597 | 7205/6125/7193 |
| A/B理想占空比差 | 8.1008% | 8.1014% |
| A/B命令边沿差 | 3.375us | 6.750us |
| 单次死区/周期 | 5.52% | 2.76% |
| AH+BL门控交叠 | 1.075us | 4.450us |

门控交叠不是全部绕组伏秒或相线电压的硬性验收宽度；实际相线受续流/电流影响。载波变化也改变纹波和开关过程；若吸动、相间电压差或电流明显增强，支持高频下死区相关有效激励不足，不能单凭它确定唯一根因。

## 参数与输出边界

新增默认关闭开关FD6288_SINE_FIXED_12KHZ=1，仅允许与既有固定相角诊断一起启用。由统一FD_NATIVE_SINE_PWM_KHZ同时控制RAM配置覆盖与配置门禁，实际loadEEpromSettings的原频率换算生成ARR13330，避免只改数字却触发24K门禁。EEPROM参数页仍保持原24K，不写设置/BL；只刷本包主程序即可生效。还原24K固定版只需刷原包，不用恢复参数页。

ADC采样窗口上限24K不变，12K在范围内。CCR4仍0、正弦固定状态不走过零/六步反馈。TIM1 PSC/CKD及DTG保持原值，控制/传感器节拍不随载波改变。

## 保留记录与新增传感器摘要

保留80B停机前PWM/引脚配置快照和3096B六路PWM数字引脚记录。新增40B fd_sine_sensors，试验开始保存静态基线；只在原前台ADC处理完成后记录更新次数、过滤电流最大值、母线最低值及ADC原始电流最大值。约1.05ms一次，未新增ADC转换、PWM写入或输出策略；这不是开关瞬间峰值，也不是绕组相电流。电流单位0.01A、母线0.01V，原始电流为ADC计数。停止后冻结，下一轮覆盖。

这样即使飞控屏幕漏掉100ms脉冲，也可在归零后读采样峰值及基线增量。读取器对可选40B摘要进行两次一致读取、检查magic/ABI/trial并解析有符号电流和单位。旧24K ELF没有该符号时仍可正常读取。

## 检查结果

- 实际C路径ASan/UBSan：原载波换算得ARR13330、CCR7205/6125/7193、只发一次矢量、100ms截止；归零/失能/时钟故障停止、正油门不连续重试。
- 12K配置门禁拒绝意外24K RAM设置；原24K固定模式和ADC交接回归通过。
- 传感器摘要只在已驱动期间记录、跟踪峰谷、停止后不变、新轮重置且不改PWM。
- 引脚解析器用12K人工指定电平/边界检查；40B摘要检查单位、符号、增量与ABI。
- 关闭新开关构建HEX与当前板上24K固定版逐字节一致；新包ELF/HEX/BIN一致，读取器所需符号大小匹配。

构建参数、日志和哈希见build-args.json、build.log、verification.json。RAM7112B，FLASH代码34388B；保留既有newlib syscall/RWX链接警告。这些是逻辑与构建检查，没有电机实测。
