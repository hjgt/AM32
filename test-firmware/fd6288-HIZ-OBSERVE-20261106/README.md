## 记录与解释

复用原12404B缓冲，RAM总用量20248B不变。ABI7保留第二定位约297/299.8ms的两组快照，替换原配对原始记录；关桥后每个完成的ABC转换组记录一次，最多512组/小于5ms。时间为软件读出时间。start0为六管关闭后的软件时刻，start1为高阻CCR4写入完成时刻。

flags32表示高阻观察路径；前两组或前150us带flags16，保留而不丢弃，提示可能有旧队列/CCR预装载转换。此标记不代表之后已经退磁。高阻样本flags1只表示读寄存器时未再次看到JEOS；定位快照flags1仍是原通电窗口检查。reason253为高阻记录，255为定位快照。无驱动扇区，step只保留最后定位矢量编号。解码器提供AB、BC、CA差分，不把高阻样本的margin当作定向过零。

初段可能包含退磁/钳位；后续持续差分变化更支持运动分量。关断本身释放定位力，因此关断后运动不能独自证明关断前在动。弱信号也不能证明绝对静止。观察与记录开销须实机检查，软件测试不能代替模拟波形验证。
