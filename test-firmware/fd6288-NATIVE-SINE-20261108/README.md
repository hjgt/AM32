## 参数与预期

- Startup power 150%，900 KV，14 极，固定进角 7.5°。
- 正弦启动开，Sine range 15，Sine mode power 6；互补 PWM 开、固定 24 kHz。
- 在加载设置时对 RAM 应用本试验参数，不写设置页，不自动保存版本升级。
  方向沿用已有设置；不主动改变堵转保护设置。原目标仍禁用爬车用的 stall boost。
- 使用 AM32 已有正弦表、逐电角度推进、油门映射及退出条件。
  不执行双矢量定位、固定首发等待、早事件丢弃、补激励或重新定位。
- 油门从零缓升时先连续正弦拖动，达到原生退出条件后切六步反馈。
  range 15 不是固定 15 ms；较高油门直接跳入时仍保留原生快速退出分支。
- 原生交接会种入 `zero_crosses=20`，这不是测得 20 个真实过零。
  新摘要单独从零累计真实反馈事件，不据这项种子宣称启动成功。

这是有界台架对照：一次有效油门试验最多 3 秒；取得六次真实反馈后再观察
最多 1 秒，两者取先到者关输出。回零可以随时结束；停止后保持正油门不重启。
取得六次真实反馈后若丢反馈，保持原来的停止原则；接上之前保留原生超时推进。
正常转起来后自动停是这份台架固件的预期行为，不是完整运行固件。

## 本板衔接

保留 ADC 同组采样、JEOS 单消费、TIM16 异步换相、真实死区采样窗口及驱动保护。
正弦阶段不使用浮空相过零驱动换相。在切到六步时，先关桥，恢复三路统一 PWM
及 CH4 采样触发，再复位 ADC 获取状态和应用原生交接扇区。没有重新调相序或死区。
回零、失去解锁或故障与最后一次正弦写入交错时，禁止旧主循环重新打开三相 PWM。

## 最小测试

沿用飞控从零缓升油门的方式，先试一次。观察“持续拖动后顺滑接上”，还是
“仅低速转动／交接时停住／起步就抖动”。不要求靠反复加油门冲过异常。
结束后回零并保持供电，若需读取再操作；不要用本试验固件飞行。

摘要 `fd_native_sine` 只有 60 B，记录最近一轮的正弦步数、进入六步时间、
首个／第六个真实反馈时间、停止时间和原因。没有增加 ADC 转换或波形缓冲。
`sine_steps` 是命令角度推进数，不是机械转子转过的角度；记录的是软件时刻。
