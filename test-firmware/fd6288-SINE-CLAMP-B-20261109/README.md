## 与12K固定正弦trial7的唯一驱动分配差别

原比较值A/B/C=7205/6125/7193；保持12K、周期13331、固定相角150/269/29、power6原公式、2.3us死区和100ms上限，三路共同减去6125得到1080/0/1068。A-B=1080、B-C=-1068、A-C=12全部逐点相同。因此保留的是理想平均线电压给定；实际经过死区/续流后的电压、电流是被测量，不预先假定相同。

B低侧GPIO持续开、B高侧关，A/C继续互补PWM。不是18%六步版，不旋转磁场、不发车。CCR4仍0，原约1ms传感器节拍与40B峰谷摘要、80B配置、3096B引脚记录保留。参数页/进角/BL不写。

原正弦公式在全桥关断时实际执行，读取其三路比较值，确认B是最低值后作共同减法；再关桥更新预装载后依次设置A PWM/B LOW/C PWM。周期/死区异常、脉宽不足或保护上限过低时拒绝驱动。100ms、归零、失能、时钟故障及保持正油门不重复的边界不变。

ASan/UBSan实际C/phaseouts验证所有相间差值精确保持、实际GPIO模式、关桥单次预装载、100ms/故障/保护停止、传感器/引脚冻结。解析器新增B恒低/A-C互补PWM模式与缺失低侧检测；原12K和A→B控制回归通过。关闭新开关强制完整构建HEX与原12K包逐字节相同，新ELF/HEX/BIN及读符号核验通过。

FD6288_SINE_CLAMP_B默认0，只准与12K固定正弦诊断配合，排斥六步控制。读取器按fdSineClampApply与三个phaseout函数验证代码身份，不依赖已被优化移除的旧函数。编译保留既有newlib/RWX链接警告。仅离线检查，没有实机结果。
