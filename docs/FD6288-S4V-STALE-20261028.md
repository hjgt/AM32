# S4V：孤立边沿后持续无反馈的有限重试（未烧录）

动机：S4U第9次174.974ms仅一个合格边沿，后续零边沿，却因observed_once排除重试，390ms截止。
S4U第5次在第二轮624ms出现首边沿、657ms接管，说明重试存在成功样本，但不能证明60度优于120度。

## 策略

保留S4U全程零边沿的重试资格；新增“曾出现边沿但已持续丢失”的资格：
必须完成至少3个连续无边沿扇区，距最后一个被策略接受的边沿至少67.5ms（3×22.5ms），
当前无已接受边沿、无连续边沿计数、处于OPEN，原六段救援已消耗且没有剩余，并且未重试。
67.5ms是保守实验门槛，不是已测定的电机机械停止时间。

资格不等于立即施力：依旧只在390..410ms窗口、当前扇区到期时释放。
新合格边沿立即清零连续缺失计数；PENDING及CLOSED禁止进入重试。
缺失计数饱和于255，复用已有edge_at，未新增ADC记录或外设读取。
释放20ms、双定位30+60ms、第二次60度发车、一次第二轮救援、820ms绝对截止全部不变。
原生超时计数及安全锁存不清零，堵转保护仍可更早终止。未实现运行中的失步重捕获。
