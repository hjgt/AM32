# 正弦分支阶段总结：保留PWM分配改善线索，暂停开发

2026-11-09。分支：codex/fd6288-native-sine-20261108。用户因下周交付期限，决定优先推进已能完整启动的ALIGN—PAIR及有限重启；正弦分支保存，当前暂停，不继续旋转测试。不是因为最后一个PWM对照无效，而是完整正弦启动尚有更多未打通环节。

## 留给以后最重要的结论

**用同样的PWM分配原则，可能改善旋转正弦在本硬件上的实际激励；已验证的是固定矢量吸动增强，尚未验证连续旋转或启动成功率。**

原12K固定矢量比较值A/B/C=7205/6125/7193。三路共同减去最低值B=6125，改为1080/0/1068：B上桥关闭、下桥持续导通，A/C继续互补PWM。三组理想平均相间电压差完全不变，原角度、power6对应理想幅值、12K、2.3us死区、100ms窗口都保留；改变的是实际开关/死区/续流过程。

若以后恢复旋转试验，候选原则是每个角度计算m=min(A,B,C)，三路共同减m，并让对应最低相持续低侧导通。**不能把这次B恒低直接照搬整圈**；最低相随电角度变化，切换边界、短脉冲和关断顺序需要实现及验证。当前只实现了B为最低相的固定角测试，没有写完整旋转映射。

## 已处理及没有确认的事

- 原正弦支路曾漏开DWT启动计时、漏更新正弦期间的常规电流采样请求；均有独立修复和归档，后续不要重复当新假设。
- 三PWM共模平移到约50%已试，24K降12K也已试，均未得到明确的机械带动改善。此次有效的是进一步改变开关分配，钳位最低相。
- A/B波形大部分重合不等于三相命令相同；MCU引脚采样和下降沿间距支持命令确实不同。不能仅凭重合就判PWM没发出。
- 死区/续流及低幅值下的功率级动态是线索，尚未确认死区是唯一根因。
- 新分配没有做连续旋转、反馈交接、随机启动成功率或48K运行验证。即使以后12K旋转成功，也要另行验证目标PWM频率。

## 若将来重新投入

先做有明确时长上限的慢速旋转磁场诊断，沿用差值分配原则，先看转子能否持续跟转，暂不接反馈换向；通过后再考虑正弦到ADC反馈六步的交接。不要重新做已经完成的固定矢量、单纯降频或同幅值位置统计。此项仅记录，当前不实施。
