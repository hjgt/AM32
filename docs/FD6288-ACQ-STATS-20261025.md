# S4N-STATS: startup diagnosis without waveform recording

Latest S4N capture: hardware-backups/S4N-read-AnRbPr/capture.json.
12 trials, 11 handoffs/operator-zero completions, final zero-edge NO_LOCK with
15 startup timeouts. Prior S4M-LITE also 11/12. No-timeout successes decreased
7→2; median handoff among successes 128.68→173.63ms. Small uncontrolled batches
do not establish statistical regression, but do not support the hold change.

Next image intentionally preserves S4N drive behavior to isolate observation:
second positioning vector still holds360; no additional control parameter change.
It enables the existing bounded 24-sector aggregator independently of large
waveform diagnostics. Extra RAM1472bytes, alongside1600byte light result history.
No new ADC channels, conversions, PWM change or startup/closed protection change.

For each commanded acquisition sector, capture its phase/direction/stage,
time bounds, valid directed-margin minimum/maximum/first/last, pre-side state,
confirmation maximum, and counts for invalid/blank/pre/hysteresis/early/unarmed/
confirmation/accepted/reported/coast decisions. These are consumed ADC samples,
not every hardware conversion; missing IRQ conversions cannot be counted here.
Positioning suppresses feedback processing, so those two sectors have no samples.
The aggregator freezes at handoff or stop. It retains latest trial only, first24
sectors; old completed light summaries still retain32 trials.

This has nonzero per-sample overhead during acquisition. No waveform buffers,
new interrupt masking, formatted output or host connection is added to the ISR.
All observations remain read-only with respect to control. Existing acceptance
algorithm and 8-count hysteresis are unchanged. Min/max alone cannot establish
crossing order or prove rotor direction; reason counts and pre-state help narrow
the next investigation but are not an oscilloscope.

Object directory: obj-startup-S4J-alignnative-hold-acqstats. Trace variant35.

Read tool: tools/scripts/fd6288_sector_capture.cjs dump MATCHING.elf NEW.bin --stopped
(fresh stopped confirmation required). It supports both legacy and clean-light
ABIs and correlates sector trial ID against completed result summaries.
