# 未知引脚复查：先静态配置，再选择动态模拟/数字采集

2026-10-23，用户授权复查闲置IO，明确排除SWDIO/PA13、SWCLK/PA14。
最初仅准备只读寄存器工具；用户指出飞机不在手边，应先复用历史代码离线开发。
现已实现下述后台ADC扫描候选、读取工具和离线测试，尚未连接/采集硬件，不是扫描结果。
不改S4M、停止条件、PWM、BL或F800设置，不重启/暂停内核。

## 第一阶段

`node tools/scripts/fd6288_pin_inventory.cjs NEW.json --stopped`

仅在用户新近确认回零、停稳且电调供电后，连接既有只读OpenOCD服务。
读取GPIO A/B/F配置，候选PA3/4/7/15、PB0/3/4/7、PF1。端口读取会包含SWD寄存器位，
但SWD不列为候选、不改变配置、不用其电平作反馈分析。
六路桥臂PA8..12/PF0、三相PA0..2、母线PA5、电流PA6、信号PB5、遥测PB6、NRST/BOOT排除。
程序仅发read_memory，前后检查VTOR、桥臂和CCR零值；不能代替操作员确认真正停稳。
不对模拟模式IDR作电平解释。输出/AF引脚只标记占用待查，不自动改成输入。
PB3/PB4/PA15还可能保留调试复用，PF1需要核查时钟使用，不能直接宣布空闲。

## 第二阶段（历史证据支持离线准备，不等待连接仿真器）

根据实机MODER/AF、板级旧资料选择通道，在停机时配置单独诊断固件。
优先PA3、PA7：COMP2正端可达性是PA2相C比较器路径的关键未知。
其余候选按实际封装和ADC通道核验，不把PA15/PB7当ADC通道。
数字边沿和模拟电压分别处理；数字读0不能证明没有模拟信号。
未知脚不设输出、上下拉，不启用DAC/OPAMP。不得运行中切换未知脚模式。

动态模拟记录必须关联PWM相位、三相电压、扇区和母线电压。
不能仅凭均值接近母线一半认定中性点，也不能把悬空串扰认定外部比较器反馈。
诊断采样不得抢占现有ADC1注入过零或破坏ADC2电压/电流保护；需独立审查调度及窗口。
限定短记录、记录完冻结，停机后由SWD取回；不依靠SWD反复读IO来重建高速波形。
原先“必须先读配置才能写扫描固件”的安排撤回：历史扫描已覆盖候选ADC脚，
可先据此完成高阻模拟输入候选；实机配置检查仅作为烧录/验收前核对，不阻塞开发。

芯片可达性参考[ST DS12589](https://www.st.com/resource/en/datasheet/stm32g431cb.pdf)，
板级连接不由数据手册证明；已有比较器矩阵见FD6288-ADC-IRQ-DESIGN-20261021.md第6节。

## 历史复用依据

- `16b79dc`（2026-09-12）：ADC_PIN_DISCOVERY临时扫描，PA4/5/6/7用ADC2后台轮询，
  每脚约250Hz；PB0为ADC1 regular第三rank，约1kHz。PA3是当时原有电压rank，亦有实测。
- `27e7184`、`e7bfe34`：发现结果。PA5 7.76V→1590.5、6.79V→1391.8 counts；
  PA6零流4.7～6.6、约0.5A→65 counts；PA3 8.55V→301、6.79V→355，否定母线比例关系。
- `404f12a`：完成定位后的诊断代码清理。不是因为扫描完全没有用而删除。
- 旧PA5“1k下拉空脚”注释已被上述实测否定，不随代码恢复。
- 本地Git找到了源代码与汇总结论，未找到那次全候选脚的完整原始采样文件。
  旧证据不能证明PA3/4/7/PB0有无高速反馈；不得将“非母线”直接推成“空脚”。

## PINSCAN候选实现

构建：`FD6288_PIN_SCAN=1 node tools/scripts/build_fd6288_s4j.cjs alignclean`。
仅CUSTOM_FD6288_G431，variant32，独立obj-startup-S4J-alignclean-pinscan目录。
基于S4L-B/C控制时序（alignclean），不混入S4M前五边沿立即换相试验，其他记录器关闭。
关闭：省略环境变量或设为0，直接构建alignclean。

ADC1 regular由温度扩为温度/PA3(CH4)/PB0(CH15)，DMA长度3；
ADC2 regular保留PA5(CH13)/PA6(CH3)为前两个rank，追加PA4(CH17)/PA7(CH4)，DMA长度4。
三相ADC1 injected三个rank、触发源、采样时间、JEOS处理和保护/停止条件均不改。
新增通道47.5cycles，高阻无上下拉，GPIO只在启动时配置，SWD及其他数字候选不改模式。
共用ADC会增加regular转换占用，不能仅凭注入配置没变就保证零干扰，实机仍须核对运行。

在现有约1kHz后台回调内检查两组DMA完成及转换结束，记录512组后冻结。
每条24字节，含软件读取时刻、四候选raw、母线/电流raw、掩码后的GPIO和当时step/running。
上电先记录静态窗口；观察到running从0变1时清空开始新窗口，停转冻结；下一次起转覆盖。
约0.5s窗口，极短于后台周期的起转可能未被捕获。调度实际频率由记录时间差核对，不能假设严格1kHz。
数字位只作低速线索，不新增EXTI；模拟模式数字值无效，调试复用脚不得自动重配置。
时间戳和step属于消费时刻，两ADC组不同步，没有配套三相波形，不能据此计算过零角度。

读取：`node tools/scripts/fd6288_pin_scan_capture.cjs dump MATCHING.elf NEW.bin --stopped`。
只读且要求冻结及两次完整读取一致；只在停稳后执行，不halt/reset，不写RAM指令。
离线解析：`node tools/scripts/fd6288_pin_scan_capture.cjs decode NEW.bin`。
读取工具输出每脚min/mean/max及原始序列，针对有意义候选再设计同步高速采样；
本版不是“已找到中性点”，也不声称能排除一切窄脉冲反馈。
