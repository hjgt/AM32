# S4S：首次施力稀疏事件观察（已烧录并取得成败对照）

目的：补足旧记录缺失的首次前侧/后侧出现时间与对应ABC，不猜新的启动参数。
控制基线为S4P；不启用PLANNED_ACQ或REPOSITION。定位、功率、相序、早期边沿立即换向、
第六边沿接管、390ms截止、运行进角/保护/JEOS均保持原路径。
本版本仍有观测开销，不能声称与S4P逐周期时序完全相同或保证不影响启动。

## 固定592字节，不是连续波形

fd_edge_observe：64字节头＋22个24字节槽，magic46454f31/ABI1。
定位第二段的>=59ms与>=59.8ms各一帧（相对该定位段起点，非试验起点），
复用现有定位ADC读数及其有效性筛选；这些是检查点，不是最后一帧的保证。
前两个驱动扇区各10槽：首4个已消费三相快照，首次pre、滞环、post、accepted、invalid、confirmation。
一个样本可以占多个语义槽；不表示多个不同的ADC转换。每个槽最多写一次。
常规最大每次样本写3个槽（首批＋post＋accepted/confirmation），无堆分配或无界循环。
每帧含软件观察时间、ABC、方向归一差值、TIM1 CNT/CCR1/CCR4、step、reason、flags。
flags bit0：驱动时为现有软件有效且非消隐；定位时为现有定位窗口筛选。
bit1预期rising；bit2定位帧。定位margin没有物理含义，解码为null。

只观察：不新增ADC转换、不更改ADC配置、不在中断里打印、不反馈到控制决策。
普通重复样本仅做资格检查；无需快照则不读附加定时器寄存器、不更新日志。
第二驱动扇区关闭即冻结；若先归零/故障/截止，也关闭当前扇区并冻结。
下一次启动会覆盖，必须在成功/失败后分别归零读取，不能把不同次数据拼成同一次。
继续保留轻量结果、原扇区统计、定位统计。大波形记录仍关闭。

## 开销与证据限制

max_cycles/calls测量有快照工作时的局部路径，含快照参数读取/写入，不含完整ISR、外部资格判断、
成本统计自身、启动清零592字节与扇区边界操作。max_cycles/160即us，必须实机读取后才能报告数值。
构建时只审查了有界存储路径；后续实机局部耗时见文末，不以主机运行耗时替代MCU耗时。
未观察到的槽不证明物理上从未发生过零，消隐帧/混合转换被丢弃等仍可能遗漏事件。
首4帧是已处理的ADC序列，不是所有原始转换；时间为软件读出附近，不是硬件采样时刻。
TIM1寄存器值亦为读出时刻；不能把它们当作每个ADC rank精确采样相位。
记录外后续运动仍依赖旧轻量/扇区数据；这不是位置传感器，也无法独立证明机械方向。

## 2026-10-28 实机成败对照

已烧录并校验主固件，保留BL及EEPROM。日志与原始数据位于
`hardware-backups/S4S-flash-i1kiSr/`；详见该目录`PAIR-ANALYSIS.md`。
失败内部trial14、成功trial15，两次settings_hex完全一致，均已归零读取冻结数据。

成功样本也未在前两个驱动扇区取得合格边沿；经历原六段短周期救援后，
223.345ms才报告首次边沿，282.582ms完成六边沿接管。失败到390ms仍为零边沿。
因此不能把首两扇区无边沿、或早期post到pre变化，单独认定为必然失败的特征。
定位末段有效ABC及首次驱动有效ABC已存在差异，但电压快照不能证明机械角度或反转。
两次局部记录工作最大441cycles（2.75625us），不是完整ISR耗时，不能据此宣称无扰动。

本次只归档分析，不修改定位时长、过零极性、消隐或保护，不生成新HEX。
下一项建议为相同控制基线上隔离定位策略的单变量比较；先复核无定位启动的入口与预算，
避免直接混用S4J的500us等待、进角设置及300ms截止而把多项差异归因于定位。
