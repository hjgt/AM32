# FD6288 / G431：ADC 中断、时间戳与定时换向审查

日期：2026-10-21。状态：**设计，不是已实现或已验收的固件**。
更新：用户随后授权实施，现有 [S4J 候选](../test-firmware/fd6288-startup-S4J-20261021/README.md) 已实现并编译非阻塞调度/JEOS双开关；下文仍保留完整设计目标。硬件采样时间戳、采样年龄补偿和插值未实施，只有软件到达/接受/调度时间；候选未上板验收。
基线：S4I-FIRST30 variant 24；2S、约 1000KV、14 磁极（7 极对）。
本轮不刷写、不启动电机、不扫描 GPIO，不改变控制算法、设置区或保护。

## 1. 已证实与尚未证实

- 现役 PA0/PA1/PA2 为三相分压，PA5 为母线电压，PA6 为电流；后两项有动态标定证据，见移植说明 C07/C10。
- 旧文档将 PA5 判为空脚、PA6 判为中性点的推理撤回。三相等阻只能作为连接线索，不能排除经电源、地、保护器件形成的间接路径。
- 三路相电压是同一 PWM 触发下的顺序转换，并非同时采样。软件平均中性点依赖分压比例、采样窗口和瞬态条件，不能宣称无条件等价、无需校准。
- 原厂曾正常工作说明存在可行控制方案，不证明它使用哪一种外设。未读取原厂运行寄存器或完成反汇编，不声称复原原厂架构。
- 约 10% 起转失败不能视作已可飞；高油门停止仍未定位，原生堵转保护当前也不能宣称验收。

## 2. 现役代码路径与主要发现

| 环节 | 当前实现 | 审查结果 |
|---|---|---|
| 采样 | `Mcu/g431/Src/adc.c`，TIM1 CH4 下降触发 ADC1 injected A/B/C | 基准 PWM 上限 24kHz；一个周期一组，JEOS 不是 FIFO |
| 处理 | `TIM6_DAC_IRQHandler → tenKhzRoutine → getBemfState` | 标称 20kHz，1MHz 定时器 ARR=50，实际理想间隔 51µs；不能把这个视为最坏延迟保证 |
| 检测 | `comparator.c` 读取新 JEOS、清标志、读 JDR；重构中性点 | 换向后丢弃一组有效样本；先前侧再后侧，滞环 8 counts；按速度需 1 或 2 个后侧确认 |
| 获取阶段 | `fdRevObserveEdge` / S4I 状态机 | 首次边沿 500µs 等待及后续规则独立存在；不与闭环轮询忙等混淆 |
| 闭环 | `zcfoundroutine` | 用处理时刻读取/清零 TIM2，计算延时，再在 ISR 内 while 忙等并直接 commutate |
| 硬件比较器原生路径 | `interruptRoutine → TIM16 → PeriodElapsedCallback` | 本 target 强制 old_routine=1，没有采用它；不可直接调用复用全部副作用 |
| 优先级 | TIM6 和 TIM16 初始化均 priority 0；DShot DMA 1、EXTI15 2 | TIM6 忙等会延迟同级中断，亦影响低优先级工作；主循环还有动态调整 COM_TIMER 优先级的代码，实施前须统一审计 |

**关键结论：仅打开 JEOS 中断不够。必须同时移除新路径的等待式 ISR，明确采样所有权和换向调度所有权。**

第七次失败 300ms 中处理 5866 组新数据，支持获取阶段约 19.6kHz，但不能外推为所有闭环时刻都如此。6000RPM 时一个 60° 扇区约 238µs，51µs 相当于 12.85°电角度；这是轮询间隔换算，不是测得的总相位误差。ADC 本体分辨率与时间分辨率是两个问题。

## 3. 建议架构及不变量

建议分两步启用，默认关闭新实验开关，仅针对 CUSTOM_FD6288_G431。

1. **先建立非阻塞调度基线**：原轮询提供边沿，闭环只提交换向请求，TIM16 执行。保持功率、资格门限、首相等待、500µs 首边沿策略不变。
2. **再切换采样消费端到 JEOS**：ADC 完成中断做短小采样快照与检测，TIM6 不再读取/清 JEOS。ADC1 regular 温度及 ADC2 电压电流保留独立路径。

目标流程：PWM 触发 → ADC 序列完成 → 带时刻/相序代号的样本 → 资格判定 → 换向请求 → TIM16 到期执行。

- 一组 ADC 数据只能由一个消费者处理；不能轮询和 IRQ 各读一遍。
- 一个扇区最多接受一次过零、保留一个有效换向请求。
- 每次桥状态变更递增 `sector_epoch`。跨换向采样、旧 epoch 请求不得作用于新扇区。
- TIM6 与 ADC IRQ 不同时运行同一获取状态机。第一阶段获取控制留在原路径；第二阶段才明确迁移到单一事件入口，不在 IRQ 中直接复用可能忙等/改优先级的公共函数。
- 零油门、故障、停机、coast、复位和重新起转均取消待执行请求、清定时器 pending 标志并更新 epoch；TIM16 执行前再检查门控。
- coast 的观察与 bailout 另有相位语义，必须显式分流；不能因迁移 DRIVE 路径停止 coast 采样，亦不能让 coast 观察触发桥输出。

## 4. 时间戳设计：不能把 ISR 到达时刻叫采样时刻

需要分别记录 `sample_time`、`irq_entry_time`、`accepted_time`、`commutation_deadline`、`actual_commutation_time`。

- ADC1 三个 rank 的采样时刻不同；以浮空相实际采样时刻为候选边沿时间，记录 rank 偏移。重构中性点仍有跨 rank 偏差，不由时间戳自动消除。
- 首个实现用完成 IRQ 时间和 TIM1 CNT/CCR4、PWM 周期、转换时长估算采样年龄；这是**估算**。若 IRQ 延迟越过一个 PWM 周期，单次 CNT 无法唯一还原，应计入 ambiguous/stale 并拒绝用于精确调度，不能猜时间。
- 需要审查能否用 TIM1 CH4 事件与 DMA/自由运行计数器建立硬件触发时间戳；其 DMA 映射、通道冲突、读取总线延迟尚未验证，不在本设计中宣称已可用。
- 可评估现有 DWT 周期计数器作为统一单调时间基准，先确认已启用、时钟与 wrap。160MHz 下 32 位约 26.84s 回绕；仅用有界无符号差值，停机长间隔重新定基准，不跨调试 halt 推算真实电机时间。
- 不直接改现有 TIM2 时基：现役 2MHz、ARR65535 且频繁清零，32.768ms 回绕，不是全局单调时间。30ms 首相及其边界测试必须保留。
- 初版不做跨样本插值。后续只有同 epoch、同采样窗口、可信负/正侧样本才考虑插值估计过零；两次确认造成的处理延迟仍需保留记录，不为追求低延迟删除资格保护。

## 5. TIM16 定时换向设计

复用现有 2MHz TIM16 的硬件能力，但新建 target 专用调度入口/回调；不能原样套用 `PeriodElapsedCallback`，因为它会再次滤波周期、增加 zero_crosses，并带有原生模式切换语义。

- 用被接受的边沿时间加当前策略延时形成绝对 deadline；编程时扣掉从边沿到现在已消耗的时间。
- 小范围已过期：只能按明确的迟到策略执行一次并计数；超出允许迟到预算：进入现有安全停止/失锁路径。预算需通过主机测试和实测确定，不能强转一整周期等待。
- 约束计数单位、ARR+1、最小装载值、最大间隔以及无符号下溢。清 pending、装载、启用要成原子操作；共享 TIM1_UP_TIM16 向量必须检查 TIM16 实际标志。
- 周期滤波、advance、zero_crosses、bad_count 每事件只更新一次，写清是在边沿还是换向更新；保留原相序和方向。
- 中断优先级尚不硬编码最终值。必须测完整 ISR/关中断最长时长；TIM16 不应被耗时 TIM6 工作阻塞，ADC IRQ 不得饿死 DShot 和停机服务。单改 NVIC 优先级不是解决方案。

## 6. 比较器可达矩阵（G431KBU6，32 引脚封装）

以下是芯片可达性，不是板上已接通证明。依据 ST DS12589 引脚表及工程 LL COMP 输入选择。

| 信号/引脚 | 比较器可达输入 | 对替代方案的意义 |
|---|---|---|
| A / PA0 | COMP3 +，COMP1 − | 可用 COMP3 对内部 DAC 门限；门限来源/比例仍需验证 |
| B / PA1 | COMP1 + | 可用 COMP1 对内部 DAC 门限 |
| C / PA2 | COMP2 − | 需要 COMP2 + 得到参考，不能通过输出极性翻转创造模拟输入连接 |
| PA3 / PA7 | COMP2 +（分别 IO2 / IO1） | 关键待查参考候选；不是已确认中性点，也不得直接开启 DAC/OPAMP 驱动它们 |
| PA4 | COMP1 −，DAC1_OUT1 | 不直接解决 COMP2 正端参考问题 |
| PA5 | COMP2 −，DAC1_OUT2 | 已占用为母线电压；不能与同在 COMP2 负端的 PA2 同时比较 |
| PF1 | COMP3 − | 封装引出；实际接线和系统时钟占用需核对 |
| PB0 | COMP4 + | 没有已知相/基准连接证据；32 引脚封装没有引出的 PB2/PE8 作为 COMP4 外部负端 |
| PA6 | 无 COMP 模拟输入，带 COMP1_OUT 复用 | 已确认电流；输出复用能力不等于外部比较器反馈 |

COMP2 的内部 DAC/VREF 选择在**负端**，不能同时占用 PA2 负端再把 DAC 软件选到正端。PA3/PA7 是否接到合适基准，是混合极性路径的主要未知。OPAMP 若作为桥接路径，需要完整核验输入/输出路由、负载和板上冲突，不能直接使能；PA2 自身还复用 OPAMP 输出，误开可能主动驱动相分压节点。

结论：撤回“不同极性所以绝对不可用”，但也不宣称“只改几行就能用比较器”。当前最小不改板路径仍是现有三相 ADC 的事件驱动改造。

## 7. 是否追加引脚扫描

不阻塞 ADC 架构设计，不先做全引脚遍历。若需要验证比较器参考，优先 PA3/PA7，而不是再次把 PA5/PA6 当未知。

1. 先核对完整封装、GPIO MODER/AF、已用外设以及旧扫描原始数据；软件未使用不等于板上空脚。
2. 模拟候选以输入方式采样，不启用上下拉/DAC/OPAMP。与三相、母线、PWM 时刻关联；原先慢速 min/mean/max 只能找到电压/电流趋势，不能证明过零反馈。
3. 若有外部数字反馈嫌疑，用高阻输入的边沿时间观察；PA15/PB7 不是本封装 ADC 输入，不能放进 ADC 通道扫描表。SWD PA13/PA14、六路栅极、信号/遥测脚排除。
4. 带电动态扫描另出诊断固件并经用户授权；不能在运行桥上动态切换未知引脚模式。未取得数据前不改中性点来源。

## 8. 实施/验证清单与回滚边界

只编译 `CUSTOM_FD6288_G431`。新方案独立实验开关，关闭时对照同一基线构建验证二进制一致（有意元数据变化单独说明）。不改 BL、F800 设置、启动入口或参数默认值，不删除堵转/安全门控。

主机测试至少覆盖：重复 JEOS、跨扇区样本、资格确认、正反转、过期/重复请求、零油门取消、fault/coast 优先级、32位计时回绕、TIM16 ARR边界、S4I首边沿/救援/300ms预算、接管时不重复换向及双重周期滤波。

板上先确认停机输出与通讯；再做用户控制的短启动测试。记录原始新样本数、漏/旧/模糊样本、每相边沿、IRQ耗时最大值、请求deadline与实际换向误差、每次失败原因。日志必须有界，不在 IRQ printf 或存储无限波形。区分“没有物理有效过零”“采到但拒绝”“接受但换向迟到”。

先完成非阻塞调度对照，再完成 JEOS 对照；期间不同时调整启动功率、首相30ms、500µs种子等待。首轮不提高PWM频率：当前窄脉冲内三rank窗口已受限制，增加频率可能反而失去有效采样。24kHz单次采样仍约41.7µs，JEOS只消除额外消费延迟，不承诺任意精度。
