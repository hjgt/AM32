## Alignment-only observer

`fd_align_observe`:808bytes, ABI1,18 bins of5ms (6 for first vector,12 for second).
Each bin stores consumed sample count, usable count, three phase sums/min/max/
first/last. Bin times are nominal stage-relative times, not hardware timestamps.
No raw waveform ring; normal startup sector statistics/light history retained.

During alignment JEOS, the special path reads existing ADC1 injected ranks1..3
and clearsJEOS, but never calls getBemfState, advances confidence, changes
blanking, marks zcfound, or schedules a commutation. Eligibility rejects a new
completion during snapshot and conservatively requires readout inside the same
ON window (trigger floor,244timer ticks for3ranks/margin, CNT before duty).
Rejected triplets count toward total but not extrema/sums. Window screening is
not proof of analog settling. Phase rank sampling is sequential.

Frozen on alignment exit or abort; reset at next start. Reading software uses
the matching ELF and correlates trial IDs with the other records. First/last
phase changes can include inductive response, switching/measurement artifacts
and mechanical motion; stable voltages alone DO NOT prove a settled rotor.
Observation has nonzero overhead. This build changes timing AND adds observation,
so any success-rate difference cannot be attributed solely to the extra30ms.
