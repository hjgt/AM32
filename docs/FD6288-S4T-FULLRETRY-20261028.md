# S4T：完整首轮之后的一次有限重试（未烧录）

基于S4S所用S4P双矢量/JEOS/异步换向控制，复用S4R2释放及重新定位适配器。
不是回滚S4J，不改变进角、采样率、功率上限、运行闭环或启动入口/BL/EEPROM。
关闭S4S的592字节稀疏观察器，保留旧轻量、首24扇区、首次定位记录及32字节重试事件。
因此控制决策可与S4P比较，但不能声称与带观察器的S4S逐周期执行时间完全一致。

## 条件及预算

- 第一轮原定位30+60ms、原反馈/六段救援完整执行，390ms前不重定位。
- 只有第一轮从未出现合格边沿、原救援耗尽、当前处于OPEN且扇区到期，才可重试。
- 允许进入重试的窗口为试验起点后[390,410)ms。只延迟截止到该窗口，不提前抢占扇区。
  若错过窗口，停止；若第一轮出现过边沿但未接管，仍按原390ms截止，不适用此补救。
- 理想无边沿时391.5ms撤去驱动，全桥释放至少20ms；随后定位矢量整体平移两步。
  正向原定位5→6、发车2；重试定位1→2、发车4。反向原定位3→2、发车6；
  重试定位5→4、发车2。请求的旋转方向不变。20ms释放不保证转子机械静止。
- 重定位仍30+60ms，约501.5ms第二次发车；第二次允许一次原六段救援，不允许第三次重定位。
- 绝对截止为试验起点后820ms，不因边沿、归入新阶段或计数器回绕续期；成功六边沿接管后，
  沿用运行逻辑，不在820ms停机。最晚410ms进入时，余量为20+90+300ms。
- 这是实验时间预算，不是温升/电流安全的实测认证；本版未提高占空比上限，但失败时通电时间更长。

原生bemf_timeout_happened及堵转/安全锁存不清零，归零、故障、截止仍取消后续施力。
若启用原生堵转保护，它可能在实验重试前终止；不能宣称本版解决或验证了堵转保护。
运行中失步重捕获也未在本次实现。本次只针对最近的零边沿启动失败。


HEX含38640数据字节，地址0x08001000..0x0800F7FF，ELF转换HEX及BIN逐字节匹配。
SHA256：1aefbc66ab9b21e6b8b90981574b744fc8a72c7764e070a732d668571d6efad2。
生成物test-firmware/fd6288-S4T-FULLRETRY-20261028/，含HEX、匹配ELF/BIN和构建日志。

通过：新重试策略与真实适配器提取测试（外设/service桩），首轮及第二轮六边沿接管、
重试只一次、第二轮救援有限、390/410/820ms边界、回绕、归零/故障取消、释放期PWM封锁、双向重定位；
S4P/S4T在390ms之前8类合成输入差分一致；旧S4R2、native、15类host、JEOS/异步及flags互斥回归通过。
这些测试不是电机模型，不能预言实机成功率。

读取工具扇区时间合理性上界由400ms扩为1s，以容纳820ms及服务延迟，新增解码边界测试通过。
仍只存首24扇区，后续详细扇区可能省略；不扩大中断记录负担。32字节重试事件继续提供
释放、重定位、第二次首边沿、接管及结束时间，轻量记录提供结果。不要声称第二轮完整波形已记录。
