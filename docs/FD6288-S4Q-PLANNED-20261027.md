# S4Q：计划换向与反馈接管分离（未实机验证）

## 依据与限制

S4P trial12 没有有效过零，390ms截止；trial13成功，8个有效边沿、4次等待超时，217ms接管。
用户观察成功样本非常平顺，不能从软件超时计数推断机械卡顿。
两次定位末段B相电压均仍在变化，不能证明固定90ms定位已让转子稳定。
本版测试的是“启动过程中孤立反馈改变计划节奏”的影响，不声称已找到根因。

复查S1/S2：12ms加速至4ms、固定相位/周期窗口曾导致少反馈或拒绝晚边沿；
不能把强拉转动误称闭环成功。本版不是直接恢复S2，当前JEOS/定位/相序也已不同。

## 修改

- 基于S4P，定位仍为30+60ms、保持功率360、相序5→6→2（反向3→2→6）。
- 计划驱动周期从16ms开始，逐步每次减1ms，最低8ms；获得两个连续合格反馈后暂停加速。
- 每个扇区最多一个ADC有效边沿；前五个只观察，不提前换向。
- 无反馈扇区清除连续资格；不把计划步进记为真实过零或原生反馈超时。
- 资格条件：边沿位于扇区1/16至15/16；相邻真实边沿周期为上一计划周期的0.5～1.5倍；
  相位变化不超过上一周期1/4。这是实验性电气筛选，不是机械方向测量。
- 连续六步合格后，按真实边沿周期与现有进角计算下一换向时间；与计划边界误差不超过1/4周期才接管。
  不满足则继续计划驱动；不会凭六个计数强行接管。
- 保留从试验开始390ms硬截止，包括待接管状态；没有反馈不会无限强拉。
- 启动功率请求400/上限610、闭环最低功率过渡、运行JEOS/异步换向、EEPROM与BL不改。
- 堵转保护闭环代码未改，但启动计划步进不再累计原生超时次数，因此启动阶段触发语义确有变化，
  由390ms无接管截止兜住；本版不能宣称堵转保护已验证或可安全飞行。

开关FD6288_PLANNED_ACQ=1，默认关闭，要求完整S4P基线；trace variant38。
不改其他target，保留S4P生成物。

## 观测与验证

保留相同轻量记录器，不增加中断内ADC波形拷贝。扇区exit_kind=6为计划边界，不是反馈。
仍只保存前24扇区；长失败可能截断尾部，解码器显示omitted_sectors，不能把截断当停机。
轻量汇总仍记录完整试验截止/接管；retries不包含计划步进。

主机测试覆盖：计划周期上下限、六边沿接管、相位拒绝、缺失反馈打断、重复边沿、DWT回绕、硬截止。
旧策略、异步换向测试也运行；仅证明软件分支，不证明电机稳定。
