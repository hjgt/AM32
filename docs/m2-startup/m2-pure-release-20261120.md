pure基于机主成功试转的500RPM正弦、三秒输出缓升和STABLE_PRE高速反馈修复，移除RAM波形/事件缓冲、DShot历史、峰值与耗时统计。功能性接管计数、六步状态、时间基准、斜坡质量判定和保护仍保留。FD6288_M2_PURE构建限制与记录宏确保诊断开关不包裹保护或调度状态。
