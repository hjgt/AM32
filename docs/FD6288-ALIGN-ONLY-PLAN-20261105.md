# 只定位、不发车：诊断方案（已烧录，已有肉眼反馈）

状态：2026-11-05已实现、完成离线验证和单目标编译，随后按用户要求直接烧录，写入及reset run成功，跳过读回校验；首轮肉眼观察已记录，见 [观察记录](../hardware-backups/ALIGN-ONLY-flash-20261105/RESULT-observation.md)。产物与验证见 [固件说明](../test-firmware/fd6288-ALIGN-ONLY-20261105/README.md)。基线及证据见 [最新交接](HANDOFF-20261105.md)。

用户明确：无法把示波器trigger与机械观察精确联系，只能肉眼描述转子怎么转、停在哪。本轮按这个条件收集证据，不要求录像或精确对时，不把肉眼最终停点当成90ms边界位置。

## 要区分的问题

原定发车时刻，转子相对机身是否仍在移动或回摆？继续保持同一定位矢量后，这种运动是否收敛？如果在原定发车时刻已经稳定，后续转查定位矢量切至首发矢量及预期过零方向的关系。

这是隔离定位过程的实验，不以启动成功率为指标，也不把延长通电时间作为最终启动方案。

## 已实现行为

1. 基于 ALIGN-PAIR + PB7，第一定位30ms、第二定位60ms；两段矢量和功率沿用基线。
2. 到原本发车边界，PB7拉高，保持第二定位矢量，禁止进入首发矢量及后续启动换相。
3. 首轮建议额外保持30ms，然后关闭驱动并清低PB7。额外保持上限30ms，名义总定位通电时间120ms；实际边界及服务延迟需在实现时核对。此30ms为观察窗口建议，尚无实测证明它足以收敛。
4. 单次触发后结束，禁止自动重定位、自动重试或持续通电；再次实验须重新归零后由操作者触发。既有停止/保护路径仍能提前关闭驱动。
5. 保留原90ms定位观测的解释；若扩展记录，明确标记额外保持段，不把旧观察器冻结后的空白当成“电压稳定”。

实现保持状态机处于ALIGN，屏蔽发车及重试入口；原发车边界只打标记，停止走既有inhibit、高阻关断、清PWM和取消异步换相路径。另以从trial开始的120ms截止限制迟到服务，不因迟到的标记续期。PB7实际边界和关断延迟仍待实测。

## 观察与记录

- CH1接PB7，CH2接电机B相，沿用现有接线及探头参考点；PB7第一次上升沿单次触发，保留至少触发前100ms、后40ms。
- 转子和机身做可辨识标记，观察两者的相对运动。用户已反馈拍摄困难、可以肉眼观察，首轮接受肉眼描述；若有慢动作录像则一并保存。
- 记录：自由放置/固定、开始后往哪边转、是否有明显回摆或分段动作、最后停在哪、关断后是否又有动作，以及照片和采集文件对应关系。不要求分清动作发生在PB7边界的前还是后。
- 电机历史记录为14磁极/7极对，同一定位矢量有7个等效机械位置，间隔约51.4度。不同绝对停点不直接等于定位不一致；先记录原始观察，再按电角周期解释。
- 肉眼或未与PB7对时的视频可以提供运动线索，但不能精确定位原发车瞬间。机械观察与相电压分别记录，不用B相波形代替位置证据。
- 先取得少量可解释样本；本聊天曾建议5～10次，这不是必须凑满的数量。单次若已能看清现象，先分析再决定是否补测。

## 结果如何决定后续工作

| 观察结果 | 支持的判断与下一步 |
|---|---|
| 定位过程可见明显回摆、分段动作，或各次动作明显不同 | 支持继续检查定位动力学；无法仅凭肉眼确定90ms时刻的运动状态 |
| 动作简短且重复，最终落在相同或电角等效位置 | 没有观察到明显异常；仍不证明90ms已经静止，结合电压记录决定是否转查首发矢量 |
| 只能看清关断后的停点，或动作难辨认 | 保留原始描述，本轮不足以区分定位末运动与关断回弹；不直接继续加时并统计成功率 |

## PB7语义变化

已有PB7固件：上升沿是首次发车实际桥配置完成后，下降沿是下一次换相或关断。

本计划：上升沿是原定发车边界，桥仍保持第二定位矢量；下降沿是诊断关断。照片和数据必须带版本，不能按旧语义混读。
